\section{Statement}

\subsection{Balaban's statements \status{verified quote}}

Theorem 2 (CMP 109 (1987), p.\ 259): ``Let $d = 4$, $G = SU(2)$, and let $\gamma$ be a sufficiently small positive constant, then for a sufficiently small positive $g$ there exists a bare coupling constant $g_0 = g_0(\varepsilon, g)$ such that the sequence of the effective coupling constants $g_k$ is contained in the interval $]0, \gamma]$, and $g_K = g$. Moreover, there exist constants $\beta, \beta'$, $0 < \beta \le \beta'$, such that $g_k$ satisfy the inequality $1/g^2 + \beta \log(L^k\varepsilon)^{-1} \le 1/g_k^2 \le 1/g^2 + \beta' \log(L^k\varepsilon)^{-1}$. (0.31)'' Balaban adds that the proof ``will be given in a separate paper''. It was never published (CMP 122 II p.\ 355, verbatim: ``has not been published yet, so we have Theorem 1 with the assumption'').

Theorem 1 (CMP 122 II p.\ 355): ``If the sequence of the effective coupling constants is contained in an interval $]0, \gamma]$ with a sufficiently small positive $\gamma$, then the effective densities $\rho_k$ have the form, and satisfy all the conditions and bounds, described in Sect.\ 2 [III].'' The bound (0.1) there reads $\chi_k \exp[-(1/g_k^2)A(U_k) - E_-|T_\eta|] \le \rho_k \le \exp E_+|T_\eta|$ (corrected reading, \file{BALABAN_EXCERPTS_CHECK} item 3).

\emph{Setting.} $\varepsilon = L^{-K}$, so $\log(L^k\varepsilon)^{-1} = (K-k)\log L$. $u_k := 1/g_k^2$. Recursion (CMP 109 (0.18)/(0.20)): $u_{k+1} = u_k - \beta_{k+1}(g_k)$. The increment $\beta_{k+1}$ depends on the whole history $g_0,\dots,g_k$ (CMP 109 p.\ 298, \status{verified quote}). $\beta_j(0)$ is the one-loop (Gaussian) increment; it is history-independent by definition. Balaban assumes $L$ odd, $L>11$, for the whole paper (CMP 109 pp.\ 251--252, OCR line 124, verbatim confirmed in \file{THEOREM2_PROOF_VERIFY} Step 6).

\subsection{What Balaban's Theorem 1 actually needs (\file{LEMMA_DPRIME_SWEEP} \S2, \S7)}

The quoted hypothesis of Theorem 1 is only $g_k\in\,]0,\gamma]$. The proof uses more. CMP 119 Theorem 1 (p.\ 262) assumes ``(I.0.33)'', a misnumbered reference to (0.31) of CMP 109. Its working form is CMP 119 p.\ 255--256 (2.6)--(2.9), for scales $m<n$:
\begin{itemize}
\item (2.6) $g_n \le (1 + g_n^2\beta'(n-m))^{1/2} g_m$ and $g_m \le (1+\beta_0) g_n$;
\item (2.7) $(\log g_n^{-2})^p \le (1+\beta_0)(\log g_m^{-2})^p$ and $(\log g_m^{-2})^p \le (1 + g_n^2\beta'(n-m))^{\beta_0}(\log g_n^{-2})^p$;
\item (2.8), (2.9) the same for $\varepsilon_j = g_j p_0(g_j)$ and $R_j$.
\end{itemize}
Here $\beta_0$ is Balaban's small constant ($1/7$ in CMP 122 II p.\ 389), not a coupling. \status{verified quote} for (2.6)--(2.9): page images, \file{LEMMA_DPRIME_SWEEP} \S1; the sweep itself is single-author, see \S2.3.

In $u$-variables these follow from two pairwise bounds:
\begin{itemize}
\item (P-up) $u_m \le u_n + B'(n-m)$, with no additive constant;
\item (P-low) $u_m \ge u_n + \beta(n-m) - D'$, with $\beta>0$, $D'\ge 0$ fixed,
\end{itemize}
plus the smallness condition
\begin{itemize}
\item (S) $\gamma^{-2} \ge c_{sw} D'$, $c_{sw} = \max(2, 1/(1-(1+\beta_0)^{-2})) = 64/15$ at $\beta_0 = 1/7$, and $\gamma \le \gamma_*(\beta_0,\beta,B',p_0,p_1,r,\nu,\kappa_0)$ (the conditions that literal (0.31) also needs). $\gamma_*$ is free of the $D'$-ratio conditions, but it depends on $R$ through $B'$ (it contains $\gamma^2B' \le (1+\beta_0)^2 - 1$ with $B' = 5b/4 + 2R$). The order of constants in \S6 ($R$ before $\gamma$) handles this.
\end{itemize}
$\beta_0$ must be fixed before $\gamma$.

\subsection{The weak form proved conditionally in this chapter}

\begin{theorem}[Theorem 2w (weak form)]
Let $G = SU(2)$, $d=4$, $L$ odd, $L>11$ (equivalently: $L$ odd $\ge 3$ with (H0) and Balaban's construction of $\beta_j(g)$ at this $L$ as an explicit hypothesis). There are $\gamma>0$, $g_1\in\,]0,\gamma]$, $\beta>0$, $B'\ge\beta$, $D'\ge 0$ such that for every $K\ge 1$ and every $g\in\,]0,g_1]$ there is a bare coupling $g_0 = g_0(K,g)$ with
\begin{itemize}
\item (b) $g_k\in\,]0,\gamma]$ for $0\le k\le K$, and $g_K = g$;
\item (c$'$) for all $0\le m\le n\le K$: $u_n + \beta(n-m) - D' \le u_m \le u_n + B'(n-m)$;
\item (S) holds for $\gamma$, $D'$.
\end{itemize}
Consequence: Balaban's (0.31) holds up to the additive constant $D'$ on the lower side, with constants $\beta/\log L$ and $B'/\log L$. The two-sided bound fixes $1/g_k^2$ up to constants, as required.
\end{theorem}

\section{Shooting lemmas}

Notation: $u_k = 1/g_k^2$, $t = 1/g^2$, $T(k,K) := \sum_{i=k+1}^{K}\beta_i(g_{i-1})$. Clamp $\varphi(u) := \max(u, 1/\gamma^2)^{-1/2}$. \subsection{Lemma D$'$ (shooting without early positivity) \status{proved+verified; Lean}}

Sources: \file{LEMMA_DPRIME.md} \S1--\S2; \file{LEMMA_DPRIME_VERIFY.md} grades 1, 2, 5 (CONFIRMED). Step 7 of that file also holds grades 3, 4, 6, which are CORRECTED (Remark 1 overclaim, misreads in \S5, ledger); this chapter uses none of them except through the sweep (\S2.3). Lean: \file{lean/YmLean/LemmaDPrime.lean} (\texttt{YmLean.lemma\_DPrime}, 405 lines), statement check \file{lean/VERIFY_LemmaDPrime.md}.

\begin{lemma}[Lemma D$'$]
\emph{Hypotheses.} (i) $\beta_{k+1}$ continuous on $[0,\gamma_0]$ and $|\beta_{k+1}(g)-\beta_{k+1}(0)|\le C_1 g$, $C_1$ independent of $k$, $K$. (ii) $\sup_j|\beta_j(0)|\le B$. (iii$'$) there is $J$ with $\beta_j(0)\ge\beta_\infty/2$ for all $j>J$ (this is all the proof uses of ``$\beta_j(0)\to\beta_\infty>0$'').

\emph{Constants.} $\gamma := \min(\gamma_0,\gamma_{Bal},\beta_\infty/(4C_1))$; $B' := B+\beta_\infty/4$; $D := J\cdot B'$; $D' := J(B+\beta_\infty/2)$; $g_1 := (1/\gamma^2+D)^{-1/2}$; $K_0 := J+\lceil 8D'/\beta_\infty\rceil$.

\emph{Conclusions.}
\begin{itemize}
\item (a) $T(k,K)\ge -D$ for all $k<K$ along any couplings in $]0,\gamma]$.
\item (b) For every $K\ge 1$ and $g\in\,]0,g_1]$ there is $g_0$ with all $g_k\in\,]0,\gamma]$ and $g_K = g$.
\item (c) $u_K + (\beta_\infty/4)(K-k) - D' \le u_k \le u_K + B'(K-k)$. The upper side has no constant.
\item (d) For $K\ge K_0$: literal (0.31) with lower constant $\beta_\infty/8$, and shooting for every $g\in\,]0,\gamma]$. If every $\beta_j(0)>0$: literal (0.31) for all $K$ (Step 8 = Lemmas D + E).
\end{itemize}
\end{lemma}

\emph{Proof idea.} Clamped flow $\tilde u_{k+1} = \tilde u_k - \beta_{k+1}(\varphi(\tilde u_k))$ is continuous in $u_0$. Its tail sums lie in $[-D, B'(K-k)]$ for every $u_0$, because clamped couplings lie in $]0,\gamma]$. IVT on $[t-D,t+B'K]$ gives $\tilde u_K = t$. Then $\tilde u_k\ge t-D\ge 1/\gamma^2$ for $g\le g_1$, so the clamp is never active. The bound is derived for the clamped flow first; there is no circularity. For history-dependent $\beta$ this proof needs $\beta_{k+1}$ defined and continuous on the whole cube $]0,\gamma]^{k+1}$; see L5 in \S2.4.

\emph{Lean.} The Lean hypotheses are weaker (ContinuousOn instead of $C^1$; (iii$'$) instead of convergence). Step 8 is \texttt{lemma\_DPrime\_step8} (\file{lean/YmLean/LemmaDE.lean}). Lean covers one-argument $\beta_j(g)$ only, not the history form.

\begin{remark}[Remark 4]
Without $g\le g_1$, (b) can fail at small $K$ ($\beta_1=\beta_2=\beta_3=-0.8$, $K=3$, $g=\gamma$). \status{proved+verified}
\end{remark}

\subsection{Prop.\ 2.1, anchor-free identity \status{proved+verified}}
