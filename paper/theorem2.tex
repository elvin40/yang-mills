\begin{lemma}[Lemma D$'$]\label{lem:Dprime}
\emph{Hypotheses.} (i) $\beta_{k+1}$ continuous on $[0,\gamma_0]$ and $|\beta_{k+1}(g)-\beta_{k+1}(0)|\le C_1 g$, $C_1$ independent of $k$, $K$. (ii) $\sup_j|\beta_j(0)|\le B$. (iii$'$) there is $J$ with $\beta_j(0)\ge\beta_\infty/2$ for all $j>J$ (this is all the proof uses of ``$\beta_j(0)\to\beta_\infty>0$'').

\emph{Constants.} $\gamma := \min(\gamma_0,\gamma_{Bal},\beta_\infty/(4C_1))$; $B' := B+\beta_\infty/4$; $D := J\cdot B'$; $D' := J(B+\beta_\infty/2)$; $g_1 := (1/\gamma^2+D)^{-1/2}$; $K_0 := J+\lceil 8D'/\beta_\infty\rceil$.

\emph{Conclusions.}
\begin{itemize}
\item (a) $T(k,K)\ge -D$ for all $k<K$ along any couplings in $]0,\gamma]$.
\item (b) For every $K\ge 1$ and $g\in\,]0,g_1]$ there is $g_0$ with all $g_k\in\,]0,\gamma]$ and $g_K = g$.
\item (c) $u_K + (\beta_\infty/4)(K-k) - D' \le u_k \le u_K + B'(K-k)$. The upper side has no constant.
\item (d) For $K\ge K_0$: literal (0.31) with lower constant $\beta_\infty/8$, and shooting for every $g\in\,]0,\gamma]$. If every $\beta_j(0)>0$: literal (0.31) for all $K$ (Step 8 = Lemmas D + E).
\end{itemize}
\end{lemma}

\emph{Proof idea.} Clamped flow $\tilde u_{k+1} = \tilde u_k - \beta_{k+1}(\varphi(\tilde u_k))$ is continuous in $u_0$. Its tail sums lie in $[-D, B'(K-k)]$ for every $u_0$, because clamped couplings lie in $]0,\gamma]$. IVT on $[t-D,t+B'K]$ gives $\tilde u_K = t$. Then $\tilde u_k\ge t-D\ge 1/\gamma^2$ for $g\le g_1$, so the clamp is never active. The bound is derived for the clamped flow first; there is no circularity. For history-dependent $\beta$ this proof needs $\beta_{k+1}$ defined and continuous on the whole cube $]0,\gamma]^{k+1}$; see L5 in \S2.4.

\emph{Lean.} The Lean hypotheses are weaker (ContinuousOn instead of $C^1$; (iii$'$) instead of convergence). Step 8 is \texttt{lemma\_DPrime\_step8} (\file{lean/YmLean/LemmaDE.lean}). Lean covers one-argument $\beta_j(g)$ only, not the history form.

\subsubsection{History dependence (L5) \status{open}}\label{sec:L5}

Balaban's $\beta_{k+1}$ depends on $(g_0,\dots,g_k)$. Lemma D$'$ Remark 3 (\file{LEMMA_DPRIME.md}) states the cube-continuity version (same proof). The gap is as follows (\file{THEOREM2_PROOF_v2_VERIFY} \S F).

\begin{itemize}
  \item \emph{Domain.} Balaban defines $\beta_{k+1}$ only on histories for which his Theorem 1 induction has run to step $k$ (\file{LEMMAS_DE_VERIFY} \S2 item 1). By the sweep (\S2.3), that induction uses (2.6)--(2.9), that is (c$'$) + (S), on the history, not only $g_i\in\,]0,\gamma]$.
  \item \emph{The new gap.} The clamped shooting of \S2.1--\S2.2 evaluates $\beta$ on clamped histories $\tilde g_i=\varphi(\tilde u_i)$. A clamped history can violate the growth side of (c$'$): from $\max(a,c)-\max(b,c)\ge\min(a-b,0)$ one gets only $u_m\ge u_n-D'$, not $u_m\ge u_n+\beta(n-m)-D'$. So the clamped shooting evaluates $\beta$ on histories outside Balaban's domain. The clamp proof is valid only under the cube hypothesis, which Balaban does not supply.
  \item \emph{A variant that avoids it} \status{not written}. Use a nested-interval proof in the style of \file{LEMMAS_DE_VERIFY} \S1.5, with domain $D_k=\{u_0,\dots,u_k\ge\gamma^{-2}\}$ of true (unclamped) trajectories. On such trajectories, (c$'$) up to step $k$ follows from the tail-sum bound (a$''$) of Lemma D$''$, and (S) holds by the choice of $\gamma$. So every evaluation of $\beta$ stays inside Balaban's domain. At each step $k$, keep the set of $u_0$ whose trajectory stays in $D_k$; show by IVT, step by step, that this set contains a closed interval on which $u_k$ sweeps a range that contains the next target interval. For Lemma D (all increments positive) this is written. For Lemma D$''$ the increments can be negative, so the nested intervals need new envelopes, built from the window bounds $[b(n-m)-2R-(b/4)(n-m),\dots]$. The adaptation is plausible; it is not written and not verified.
  \item Lean is one-argument only.
\end{itemize}

\subsubsection{Anchor-free identity \status{proved+verified}}\label{sec:prop21}
