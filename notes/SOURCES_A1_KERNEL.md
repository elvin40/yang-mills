## 6. Route DMS (coordinator's IDEAS_FABLE §I2): statement, checks, and the obstruction
6.1 Citation [lit-checked via secondary source; original text not read]. S. Demko, W. F. Moss, P. W. Smith, "Decay rates for inverses of band matrices", Math. Comp. 43 (1984) 491–499, doi 10.1090/S0025-5718-1984-0758197-9. Statement as quoted in arXiv math/0010243: A Hermitian positive definite, m-banded (A_{kl} = 0 for |k − l| > m), κ := ‖A‖‖A^{−1}‖, q := (√κ − 1)/(√κ + 1), λ := q^{1/m}; then |(A^{−1})_{kl}| ≤ c λ^{|k−l|}, c = ‖A^{−1}‖ max{1, (1 + √κ)²/(2κ)}. For a general invertible banded A the paper applies this to AA* (bandwidth 2m, condition number κ²), which gives λ_1 = ((κ − 1)/(κ + 1))^{1/(2m)}. Jaffard (Ann. IHP Anal. Non Lin. 7 (1990) 461–476) extends inverse-closedness to infinite matrices with exponential off-diagonal decay (not only banded). [Citation of Jaffard from memory; not checked here.]
6.2 The rate depends on κ, not on ‖T^{−1}‖ alone [P]. The brief's phrase "rate and constant depending only on the range and on ‖T^{−1}‖" is wrong: ‖T‖ enters through κ.
6.3 Finite range fails [V/P]. M_1 = Δ_π + DRD* − (J-term). 6.4 Units: the rate is not uniform on the fine lattice [P]. On the fine lattice (step η, range m = O(1) in fine steps) M_1 contains a covariant Laplacian with spectrum from O(1) (wavelength 1 in block units) to O(η^{−2}). No diagonal rescaling removes this spread: it is a ratio of eigenvalues of one block. So κ(T) ≥ cη^{−2}. T is indefinite (saddle point), so DMS must go through TT*: λ_1 ≈ e^{−1/(2mκ)} = e^{−cη²} per fine step. Over a physical distance r there are r/η fine steps: decay e^{−cηr}, which tends to 1 as η → 0. The route gives NO uniform decay. (For a positive definite operator the √κ in q would give e^{−c√(η²)·r/η} = e^{−cr}, uniform; the loss comes from indefiniteness. A two-interval Chebyshev estimate on [−C,−c] ∪ [c, Cη^{−2}] probably restores √-behaviour [I, not done], but that is no longer the textbook theorem.)

## 7. Route CT (block-level inverse-closedness): Lemma CT [P]
Setting: 𝔅 finite (finite volume, as in Balaban), ℋ = ℓ²(𝔅, μ) (§5), m(y,y′) := (μ(y)μ(y′))^{−1/2}, d a metric on 𝔅, Σ(·) as in §5.
Lemma CT. Let N̂ be self-adjoint on ℋ with kernel n̂ (w.r.t. μ) such that
 (i) |n̂(y,y′)| ≤ c_+ m(y,y′) e^{−δ d(y,y′)};
 (ii) N̂ ≥ c_− > 0.
Put ε := min{δ/2, c_−/(2c_+Σ(δ/2))}. Then the kernel g of N̂^{−1} obeys |g(y,y′)| ≤ (2/c_−) m(y,y′) e^{−ε d(y,y′)}.
Proof. Fix y′. Let f(y) := d(y,y′), ψ := e^{εf} (bounded: 𝔅 finite). N̂_ε := ψN̂ψ^{−1} has kernel n̂(y,y″)e^{ε(f(y)−f(y″))}. By the triangle inequality |f(y) − f(y″)| ≤ d(y,y″), so the kernel of E := N̂_ε − N̂ is bounded by c_+ m ε d e^{εd} e^{−δd} ≤ c_+ ε m(y,y″) d(y,y″) e^{−(δ/2)d(y,y″)}. Schur test on ℋ: for a kernel |k| ≤ m·h with h symmetric, sup_y Σ_{y″} μ(y″)|k(y,y″)| ≤ sup_y Σ_{y″}(μ(y″)/μ(y))^{1/2}h(y,y″), and the same with y, y″ exchanged; so ‖E‖ ≤ εc_+Σ(δ/2) ≤ c_−/2. Then Re⟨u, N̂_εu⟩ ≥ (c_− − ‖E‖)‖u‖² ≥ (c_−/2)‖u‖², and the same for N̂_ε*; so N̂_ε is invertible with ‖N̂_ε^{−1}‖ ≤ 2/c_−. N̂_ε^{−1} = ψN̂^{−1}ψ^{−1}. Its (y,y′) matrix element: ⟨1_y, N̂_ε^{−1}1_{y′}⟩ = μ(y)μ(y′)g(y,y′)e^{εd(y,y′)} (ψ(y′) = 1), and |⟨1_y, A1_{y′}⟩| ≤ ‖A‖(μ(y)μ(y′))^{1/2}. Hence |g(y,y′)|e^{εd(y,y′)} ≤ (2/c_−)m(y,y′). ∎
Remarks [P]. (a) No finite range is used, only (i); no Fourier analysis; no U-structure. (b) Constants depend only on c_±, δ, and Σ, which is uniform in k, j, {Ω_j} (§5). (c) The bound is the multiscale form of the Combes–Thomas estimate; Jaffard's theorem gives the same conclusion with less explicit constants.

## 10. Theorem A1′ (what is proved here) [P given (K) and (C)]
