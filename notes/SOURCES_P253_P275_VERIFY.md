## V1. Check (1): Lemma T (target §3.1) — CONFIRMED, with one scope caveat

Re-derivation [P], U = 1, abelian components, one step.
- Lemma S (P254_VERIFY V7) for each chain layout: Q̃_freeB = Q_str(B + Dλ_B), Q_axB = Q_str(B + Dλ^ax_B). Subtract: Q̃_freeB − Q_axB = Q_strD(λ_B − λ^ax_B). Q_str(Dλ)(c) = Σ_{x∈B(c_−)}L^{−d}[λ(x′) − λ(x)] = λ̄(c_+) − λ̄(c_−), λ̄ = block average (x ↦ x′ = x + Le_μ is a bijection B(c_−) → B(c_+)). So the difference is Dσ_B, σ_B = block average of λ_B − λ^ax_B. Correct.
- μ_B := σ_B∘y is constant on blocks. So Dμ_B = 0 on block bonds, and every chain lies in a block (P254 Lemma S(b)). Hence λ^ax_{Dμ_B} = 0 and Q_ax(Dμ_B) = Q_str(Dμ_B) = D(block average of μ_B) = Dσ_B. So Q̃_freeB = Q_ax(B + Dμ_B). The target's general step "λ^ax_{Dμ}(x) = −(μ(x) − μ(y(x)))" is also right (telescoping along the axial chain), but it is not needed.
- Unipotence: μ_{Dμ_B} = 0 by the same chain argument, so T²B = B + 2Dμ_B, (T − I)² = 0, T^{−1} = I − Dμ_·. ∂D = 0 gives ∂T = ∂. Correct.
- Norm: |B⟨Γ⟩| ≤ max_Γ|B(Γ)| ≤ ℓ^{1/2}S_y^{1/2}, ℓ ≤ d(L−1)/2 ≤ dL. So |σ_B(y)|² ≤ (2(dL)^{1/2})²S_y = 4dL·S_y. A corridor has L^{d−1} bonds, each carrying σ(c_+) − σ(c_−), |·|² ≤ 2|σ(c_+)|² + 2|σ(c_−)|². A block is an end of ≤ 2d corridors. So ‖Dμ_B‖² ≤ L^{d−1}·2·2d·Σ_y|σ_B(y)|² ≤ 16d²L^dS_b. Hence ‖Dμ_B‖ ≤ 4dL^{d/2}S_b^{1/2} ≤ 4dL^{d/2}‖B‖. CONFIRMED (the constant is even ≤ 2dL^{d/2} with ℓ ≤ dL/2).
