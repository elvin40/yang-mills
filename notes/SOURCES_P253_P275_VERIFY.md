- Lemma S (P254_VERIFY V7) for each chain layout: Q̃_freeB = Q_str(B + Dλ_B), Q_axB = Q_str(B + Dλ^ax_B). Subtract: Q̃_freeB − Q_axB = Q_strD(λ_B − λ^ax_B). ## V4. Check (4): fine-scale counterexample (target §4.4) — CONFIRMED in order; constant CORRECTED

Regular class used: CMP 99 (3.35)–(3.36) as quoted in A18 1.2–1.3: in a gauge on each index-j cube, |A| < c_rMα(L^jη)^{−1}, |∇^ηA| < c_rMα(L^jη)^{−2}, |∂^{η*}∂^ηA| < c_rMα(L^jη)^{−3}. This implies plaquette angle ≤ 2η²c_rMα(L^jη)^{−2}.
Explicit configuration [P]. G ⊃ U(1) through a Cartan direction H (|H| = 1), so the example is abelian. Let ℓ := L^jη, j ≥ 1, and let the interface be the hyperplane between the fine layers x_1 = 0 and x_1 = η, aligned with the L^j-block boundaries. Put
 A^out := 0 on all bonds;
 A^in := a·cos(2π(x_1 − η)/ℓ)·H on every e_2-bond at x_1 ≥ η, 0 on all other bonds, with a := c_rMαℓ^{−1}/(4π²).
Both fields are regular: |A^in| ≤ a, |∇A^in| ≤ 2πa/ℓ, |∂*∂A^in| ≤ (2π)²a/ℓ², all below the bounds. Both have the same block averages on every L^j-block (the discrete sum of cos over a full period ℓ = L^jη of the lattice is 0 for L^j ≥ 2; A^out averages to 0). Glue: Ũ = A^out for x_1 ≤ 0, A^in for x_1 ≥ η, crossing e_1-bonds = 0. The (1, 2)-plaquette with e_2-bonds at x_1 = 0 and x_1 = η has angle η(a − 0) = ηa. The allowed angle is 2η²c_rMαℓ^{−2}. Ratio = ηa/(2η²c_rMαℓ^{−2}) = ℓ/(8π²η) = L^j/(8π²), unbounded as j → k → ∞. The angle (the conjugacy class of Ũ(∂p)) is gauge invariant, so no gauge gives (3.35) on a cube containing p.
Verdict. The claim (a gluing lemma with jump bounded by the averaging constraint is false on T_η, by a factor of order L^j, no gauge repairs it) is CONFIRMED. The printed ratio "4L^j" is a worst-case heuristic; the explicit example gives L^j/(8π²) when (3.36) is also imposed on both fields. Order L^j is what the argument needs. If only (3.35) is imposed, a = c_rMαℓ^{−1}/(2π) and the ratio is L^j/(4π).
