## 3. Route 1: β_{k+1} on the clamped cube ]0, γ]^{k+1}

Notation. F_k(g, I) := E^{(k+1)} produced by the small-field step k+1 from own slot g and inputs I = (V^{(1)}, …, V^{(k)}). ‖·‖_l = the HHIST §6 norm. 3.1 Definition [P given the inputs named]. For h_k = (g_0, …, g_k) ∈ ]0, γ]^{k+1}, define recursively (HHIST §5):
  E^{(l+1)}(h_l) := F_l(g_l, V^{(1)}(h_0), …, V^{(l)}(h_{l−1})),
  β_{l+1}(h_l) := Π(E^{(l+1)}(h_l)) + β^{(0)}_{l+1},
  V^{(l+1)}(h_l) := −β_{l+1}(h_l)A + E^{(l+1)}(h_l),
with the plaquette (marginal) coefficient of step l+1 equal to 1/g_l² (slot l). Counterterm booking (the item H0_VERIFY l. 96 / l. 214 assigns to B7): the counterterm of step l is −β_l(h_{l−1})A, i.e. the coefficient read off the same slot vector. The p. 298 cancellation ("the first expression there is cancelled by the first expression in (4.42)") is a coefficient identity: β_l(h_{l−1}) is by definition the marginal coefficient of E^{(l)}(h_{l−1}). So the cancellation holds for every slot vector, not only on the trajectory [P, given the reading 2.1 that β_l is defined as that coefficient].

3.4 Path B (holomorphic route) and the joint-vs-separate question [P for the logic; R to HHOL §4.1].
- Statement used. Osgood's lemma: a function on an open set of C^n that is continuous (or locally bounded) and holomorphic in each variable separately is holomorphic. Hartogs' theorem removes the boundedness hypothesis, but only for finitely many variables. Both are standard (e.g. Hörmander, An Introduction to Complex Analysis in Several Variables, §2.2; Osgood 1899, Hartogs 1906) [I: textbook citation, section number not re-checked].
- Why finite dimension suffices. β_{k+1}(h_k) is a scalar function of k+1 complex slots. The inputs V^{(l)} are infinite families, but they are intermediates. Osgood is applied to the scalar composite on the polydisc P_{ρ_0}(x) ⊂ C^{k+1}, so no Banach-space version is needed.
- Hypotheses. (H-sep) Holomorphy in slot i with the other slots fixed: slot i enters step i+1 holomorphically (HHOL 2.4); it enters step l+1 > i+1 only through the inputs. Each later step integrand is affine in the inputs inside the exponent, with a majorant uniform on 𝔅 (HHOL 2.3–2.4), and the polymer sums converge uniformly (HHOL 3.3). So if z ↦ V^{(m)}(X, U; z) is holomorphic pointwise in (X, U) and stays in 𝔅, then z ↦ F_l(g_l, I(z))(X, U) is holomorphic (Fubini + Morera + Weierstrass on uniformly convergent sums). Induction in l gives (H-sep) [R: HHOL §2–§3]. (H-bd) |β_{k+1}| ≤ M on P_{ρ_0}(x) (HHOL 3.4) [R]. Osgood (bounded form) then gives joint holomorphy, so continuity on the real cube.
- HHOL §4.1 states the same conclusion through "composition of holomorphic maps"; Path B makes it rest on scalar Osgood instead. The VERIFY of HHOL graded §4 items (3) CONFIRMED and (2) CORRECTED as a reduction; the X-mode correction ρ_0 → ρ_0/√2 (VERIFY (1)) only changes the radius.
- Choice. Path A needs only (SM) and the one-slot disc of HHOL §2–§3. Path B needs the full polydisc of HHOL §4.1. Continuity needs only Path A. Path B is a cross-check, and it gives real-analyticity, which no consumer uses.

## 4. Route 2: nested-interval Lemma D″ on true trajectories (no clamp)

4.1 Setting. True flow u_{k+1} = u_k − β_{k+1}(h_k), h_k = (u_0^{−1/2}, …, u_k^{−1/2}). Balaban's domain at step k: Dom_k := histories h_k with u_i ≥ γ^{−2} (i ≤ k) that satisfy (c′) and (S) for indices ≤ k. Reading [I, causality]: the step-(k+1) construction uses the couplings g_0, …, g_k only, so Balaban's induction runs to step k+1 on every h_k ∈ Dom_k (the sweep conditions are comparisons among already-built scales; CMP 109 p. 259: no "special asymptotic behavior" assumed). D_k := {u_0 : h_k(u_0) ∈ Dom_k}.
Hypotheses.
 (i-tr) |β_{k+1}(h_k) − β_{k+1}(0)| ≤ C_1g_k for h_k ∈ Dom_k, C_1 free of k, K (7′ restricted to trajectories; weaker than 7′).
 (C-tr) For each k < K, u_0 ↦ β_{k+1}(h_k(u_0)) is continuous on D_k.
 (5.1) T_0(k, K) ∈ [b(K − k) − 2R, b(K − k) + 2R] for 0 ≤ k < K.
Constants as in v4 §2.2: γ := min(γ_0, γ_Bal, b/(4C_1)); β = 3b/4; B′ = 5b/4 + 2R; D′ = 2R; g_1 := (γ^{−2} + 2R)^{−1/2}.

4.2 Lemma D″-nest [P]. Under (i-tr), (C-tr), (5.1): for every K ≥ 1 and g ∈ ]0, g_1] there is u_0* with h_K(u_0*) ∈ Dom_K and u_K(u_0*) = g^{−2}. Along it, u_k − t ∈ [T_0(k, K) − (b/4)(K − k), T_0(k, K) + (b/4)(K − k)] and (c′) holds: u_n + β(n − m) − D′ ≤ u_m ≤ u_n + B′(n − m), 0 ≤ m ≤ n ≤ K.
Proof. Put t := g^{−2} ≥ γ^{−2} + 2R and the envelopes
  p_k := t + T_0(k, K) − (b/4)(K − k),  q_k := t + T_0(k, K) + (b/4)(K − k),  p_K = q_K = t.
(e1) p_k ≥ γ^{−2}: by (5.1), p_k ≥ t + (3b/4)(K − k) − 2R ≥ t − 2R ≥ γ^{−2}.
(e2) Recursion: p_k − β_{k+1}(0) + b/4 = p_{k+1}, q_k − β_{k+1}(0) − b/4 = q_{k+1} (since T_0(k, K) = β_{k+1}(0) + T_0(k+1, K)).
Claim P(k): there is a compact interval I_k = [a_k, c_k] ⊆ D_k with u_k(a_k) = p_k, u_k(c_k) = q_k, and p_i ≤ u_i ≤ q_i on I_k for all i ≤ k.
- P(0): I_0 := [p_0, q_0]; u_0 is the identity. h_0 = (u_0^{−1/2}) with u_0 ≥ p_0 ≥ γ^{−2} lies in Dom_0 (no pairs).
- P(k) ⇒ P(k+1). On I_k ⊆ D_k, u_{k+1} = u_k − β_{k+1}(h_k) is defined and continuous (C-tr). By (i-tr) and C_1g_k ≤ C_1γ ≤ b/4: u_{k+1}(a_k) ≤ p_k − β_{k+1}(0) + b/4 = p_{k+1}, and u_{k+1}(c_k) ≥ q_k − β_{k+1}(0) − b/4 = q_{k+1} (e2). Note p_{k+1} ≤ q_{k+1}. By the IVT, c_{k+1} := min{x ∈ I_k : u_{k+1}(x) = q_{k+1}} exists, then a_{k+1} := max{x ∈ [a_k, c_{k+1}] : u_{k+1}(x) = p_{k+1}} exists (if a_k ≤ c_k; the case c_k < a_k is symmetric, with the interval oriented the other way). On the open interval between them u_{k+1} takes neither endpoint value, so by the IVT it lies in ]p_{k+1}, q_{k+1}[. So p_{k+1} ≤ u_{k+1} ≤ q_{k+1} on I_{k+1}, and u_{k+1} ≥ γ^{−2} by (e1).
  Domain: for u_0 ∈ I_{k+1} and m < n ≤ k+1, u_m − u_n = T(m, n) = Σ_{i=m+1}^{n} β_i(h_{i−1}), each h_{i−1} ∈ Dom_{i−1} (by P(i−1)), so by (i-tr) and (5.1), T(m, n) ∈ [(3b/4)(n − m) − 2R, (5b/4)(n − m) + 2R]. The left end gives the lower side of (c′) with D′ = 2R; the right end is ≤ B′(n − m) because n − m ≥ 1. (S) is g_i ≤ γ, true by u_i ≥ γ^{−2}. So h_{k+1} ∈ Dom_{k+1}, i.e. I_{k+1} ⊆ D_{k+1}.
- P(K): p_K = q_K = t, so u_K = t at a_K. The envelope and (c′) bounds are those carried by the induction. ∎

(3) The envelopes are built from T_0 exactly, not from window bounds; this is what makes negative single-step increments harmless, the point v4 §2.4 called "new envelopes" [P]. (4) With q_k − p_k = (b/2)(K − k) > 0 for k < K, the intervals are non-degenerate until the last step.
4.3 Lemma D′-nest [P, same proof]. Replace (5.1) by D′'s (ii), (iii′), use C_1γ ≤ β_∞/4, and put p_k := t + T_0(k, K) − (β_∞/4)(K − k).
