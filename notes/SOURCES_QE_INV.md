## 2. Exact identity and the holonomy expansion (one layer first) [P given (KE), (H_Q)]
2.1 Dressed kernel. (𝓔_UX)(b) := Σ_y E(b, y)·Ad U(Γ_{y→b})X(y). Path rule: Γ_{y→b} := reverse of the Q-contour Γ_{y←b} if b ∈ supp q(y, ·); otherwise the axial path from y_− to b in a FIXED coordinate order (call this order π; π_w(o) = axial path o → w).
2.2 Exact free identity [P]. Σ_b q(y′, b)E(b, y) = δ_{yy′} for all y, y′ ∈ 𝔅, because Q(1)H_1 = I. In the free single-layer case this is Q(1)𝓔_1 = I (checked [N] to 1e−9 in k0_d.py and below, §6).
2.3 Block formula [P]. For y′ ≠ y let τ := π_{y′_−}(y_−) (axial y_− → y′_−; empty if y_− = y′_−). Put λ_b := closed loop based at y_−: τ, then Γ_{y′←b}^{−1} (y′_− → b), then Γ_{y→b}^{−1} (b → y_−). Then Ad U(Γ_{y′←b})Ad U(Γ_{y→b}) = Ad U(τ)·Ad U(λ_b)^{±1} (orientation convention only), and by 2.2
 (Q^{tr}𝓔_U − I)(y′, y) = Ad U(τ)·Σ_b q(y′, b)E(b, y)[Ad U(λ_b) − 1].
 Diagonal y′ = y: τ empty and λ_b is a path followed and then retraced, so the block is 0 EXACTLY. This is the 2e−14 of SOURCES_EU_VERIFY §4. Pure gauge U = g(x)g(x′)^{−1}: every Ad U(λ_b) = 1, so Q^{tr}𝓔_U = I exactly (EU_VERIFY: 8e−14).
2.4 Cone-area lemma [P]. Let λ be a closed fine lattice loop through o. For a bond (w, w′ = w + ηe_κ) of λ, the lasso π_w(o)·(w, w′)·π_{w′}(o)^{−1} bounds a lattice surface of Σ_{κ′ after κ in π}|w_{κ′} − o_{κ′}|/η ≤ |w − o|_1/η plaquettes (the two axial paths agree up to the κ-leg and then run parallel at distance η). The loop is the ordered product of these lassoes (telescoping), each lasso being conjugated by a unitary; and |Πh_i − 1| ≤ Σ|h_i − 1| for unitaries. Bonds of λ that extend π_w(o) to π_{w′}(o) give a degenerate lasso (zero plaquettes). Hence, in a region where |U(∂p) − 1| ≤ α(η/ℓ)²,
 |U(λ) − 1| ≤ α·(η/ℓ²)·Σ_{w ∈ λ, non-axial bonds}|w − o|_1 ≤ α·len′(λ)·max_{w∈λ}|w − o|_1 / ℓ²,
 len′ = length of the non-axial part of λ. The bound is LINEAR in the distance |b − y_−|, not quadratic: the axial legs τ and π_b(y_−) cost nothing.
2.5 Area of λ_b [P]. Base o = y_−. τ is axial from o: cost 0. Γ_{y→b}: axial from o (cost 0) unless b ∈ supp q(y, ·), where it is a Q-contour of length ≤ (d + 1)ℓ within distance (d + 1)ℓ of o. Γ_{y′←b}: a Q-contour of length ≤ (d + 1)ℓ (for Q_98: back along the μ-line ≤ ℓ, then Γ_{y′_−,x} of length ≤ dℓ [I-small: Γ_{c_−,x} of CMP 98 (52)–(53) taken axial]), within distance |b − y_−|_1 + (d + 1)ℓ of o. In block units (ℓ = 1):
 𝒜(λ_b) ≤ (d + 1)(|b − y_−|_1 + 3(d + 1)), so |Ad U(λ_b) − 1| ≤ 2α_F(d + 1)(|b − y_−|_1 + 3(d + 1)).
2.6 Schur test [P]. With f(b, y) := (d + 1)(|b − y_−|_1 + 3(d + 1)):
 row sum (fixed y′): Σ_y|K^{tr}(y′, y)| ≤ 2α_F Σ_b q(y′, b)Σ_y|E(b, y)|f ≤ 2α_F·m_row, m_row := sup_b Σ_y |E(b, y)|f(b, y)  (Σ_b q = 1);
 column sum (fixed y): Σ_{y′}|K^{tr}(y′, y)| ≤ 2α_F Σ_b(Σ_{y′}q(y′, b))|E(b, y)|f = 2α_F·m_col, m_col := sup_y Σ_b(η/ℓ)^d|E(b, y)|f  (1.4).
 ‖Q^{tr}𝓔_U − I‖_{ℓ²(𝔅)} ≤ 2α_F√(m_row·m_col).
 Remainder (H_Q): Q″ sums over all bonds of B(y′_−) ∪ B(y′_+) (2d(ℓ/η)^d bonds, weight (η/ℓ)^d each), and each fine bond lies in that set for at most 2d coarse bonds y′. Schur: ‖Q″𝓔_U‖ ≤ 2d·ε″·√(m⁰_row·m⁰_col), m⁰ = the same moments with f ≡ 1.
 Result (one layer): ε_Q := ‖Q(U)𝓔_U − I‖ ≤ 2α_F√(m_row m_col) + 2dε″√(m⁰_row m⁰_col) ≤ c_Q(d, L)·Mα_0, c_Q := 40√(m_row m_col)(1 + O(Mα_0)) + 2d·c(d, L)√(m⁰_row m⁰_col)/M.
 m_row ≥ m_col in general (sup over b of a lattice sum versus the η^d-average); both are finite by (KE). This is the "lattice-sum versus η^d-sum" [I] of SOURCES_EU, now tracked: the sup form is the one the row sum needs.

## 3. Uniformity in j and k (one layer) [P given (KE)]
3.1 Scale covariance. In block units of scale j (ℓ_j = L^jη = 1) the fine spacing is 1/N, N = L^j. The weights q, the kernel E, the moments m_row, m_col, m⁰ depend on N only (not on j otherwise), and α_F is O(Mα_0) in block units at every scale (1.5). So uniformity in j is uniformity in N.
3.2 Moments uniform in N. (KE) holds with C_H, δ_H independent of N and of {Ω_j} (CMP 96 Cor. 2.8; the single-layer E_0 is the case Ω_1 = … = Ω_j = T). Then m_row ≤ C_H sup_b Σ_y e^{−δ_Hd(b,y)}(d + 1)(|b − y_−|_1 + 3(d + 1)) ≤ c(d)C_Hδ_H^{−d−1}, and the same for m_col (the η^d-sum over b of a function decaying on the unit scale is a Riemann sum, bounded uniformly in N). [P given (KE)].
3.3 Independent check of uniform decay at U = 1 (no Balaban input) [P-sketch]. In fine momentum q = p′ + 2πl: Ê_0(q) = conj ŵ_N(q)/(λ_N(q)T_N(p′)). The pole of 1/λ_N at q = 0 cancels against the pole of T_N at p′ = 0 (T_N ~ |ŵ|²/λ_N there), so Ê_0 is regular at q = 0. T_N ≥ inf T_N = 1/K_0(N) ≥ 1/195.2 (d = 4) on the real torus [N, SOURCES_EU §3], and T_N, ŵ_N, λ_N/N² converge with all derivatives in a complex strip as N → ∞. So 1/T_N is analytic in |Im p′| < κ(d) with κ independent of N, and a contour shift gives |E_0(z, c)| ≤ C e^{−κ|z−c|}. [I] the integrability of Ê_0 over the growing Brillouin zone after the shift is not written out. [N] numerics: d = 2 the measured ‖Q_U𝓔_U − I‖/α_Ad = 0.0100, 0.0100, 0.0099 at N = 3, 5, 7 (Lu = 4), §6; SOURCES_EU §4.4 shell decay factor 3–4 per unit (δ ≈ 1.2).
3.4 Volume. Every Schur sum is a sup over one row or one column of a kernel with exponential decay, so no volume factor enters. On a torus, loops λ_b that wind around the torus have no spanning surface (Polyakov loops are not controlled by regularity); their total weight is ≤ C_H e^{−δ_H·(torus size)/2} and they go into the far term of §4.3. [N] confirmed: on the d = 2, Lu = 8 torus the entrywise bound fails only on wrapped pairs (ratio 1.71) and holds on all other pairs (max ratio 0.963), §6.

## 4. Multiscale lattice and layer interfaces [P given (KE), (H_Q)]
4.1 A per-layer kernel does NOT work [P]. If 𝓔_1 := ⊕_j 𝓔^{(j)} with 𝓔^{(j)} the single-layer free kernel of scale j, then for y ∈ Λ_j at distance O(1) (block units) from Ω_{j+1}, the field 𝓔^{(j)}1_y leaks into Ω_{j+1} with size O(1)·e^{−δ·dist} = O(1), and Q_{j+1} on the adjacent bonds of Λ_{j+1} sees it. Also Q_j itself, for y near ∂Ω_{j+1}, has its corridor partly inside Ω_{j+1}. So the interface rows of Q(1)𝓔_1 differ from I by O(1), not by a small amount, and no Neumann argument is available. The brief's question "does Q(1)𝓔_1 = I hold at interfaces?" is answered: NO for a per-layer 𝓔_1.
4.2 Fix: use the free MULTISCALE minimizer H_1 (1.2) as 𝓔_1 [P]. H_1 = G_freeQ*(QG_freeQ*)^{−1} satisfies Q(1)H_1 = I on all of 𝔅, interfaces and the Dirichlet set Λ_0 included, because it is the exact free constrained minimizer (CMP 96 (2.5)–(2.6), Prop. 2.7: (QG_freeQ*)^{−1} exists with the bound (2.149) [V A1_A4_VERIFY §4]). So 2.2 holds verbatim on 𝔅, and 2.3 (the holonomy form of the defect) holds verbatim. The dressed field 𝓔_UX has the support of H_1X, so it also vanishes on Λ_0: the boundary-cutoff [I] of SOURCES_EU §5.1 disappears.
4.3 Holonomy bound across layers. Layer widths: (L^jη)^{−1}dist(Ω_j^c, Ω_{j+1}) > RM [V CMP 96 (2.2)]. Fix y ∈ Λ_j and call a term b NEAR if d(b, y) ≤ D := RM/(4L²) (d = CMP 96 (2.36), block-size weighted).
 (a) Near terms [P]. A d-geodesic of length ≤ D < RM cannot cross a whole layer, so it stays in layers j − 1, j, j + 1, where blocks have size ≤ Lℓ_j; hence the physical distance |b − y_−| ≤ DLℓ_j + O(ℓ_j) = RMℓ_j/(4L) + O(ℓ_j). The cone surface of 2.4 lies in the box spanned by y_− and the loop, inside the physical ball of that radius + (d + 1)Lℓ_j, which lies in layers j − 1, j, j + 1 for RM ≥ c(d)L (a point of layer j − 2 is at distance > RMℓ_{j−1} = RMℓ_j/L from Ω_j). There |U(∂p) − 1| ≤ α_F(η/ℓ_{j−1})² = L²α_F(η/ℓ_j)². Redoing 2.5 in ℓ_j units, with Q-leg length ≤ (d + 1)Lℓ_j (y′ may be one scale coarser) and |b − y_−|/ℓ_j ≤ L·d(b, y) + c:
 |Ad U(λ_b) − 1| ≤ 2α_F·L³(d + 1)(d(b, y) + 3(d + 1)) =: 2α_F·f_ms(b, y).
 (b) Far terms [P]. |Ad U(λ_b) − 1| ≤ 2 always. Their Schur contribution is ≤ 2·c_far·e^{−δ_HD/2}, c_far := the f ≡ 1 moments of C_He^{−δ_Hd/2}; this includes torus-winding loops.
 (c) Column normalization at interfaces [P]. A fine bond b is seen by corridors of at most two scales (j and j + 1 near ∂Ω_{j+1}), so Σ_{y′}q(y′, b) ≤ 2(η/ℓ(b))^d instead of = (η/ℓ)^d. Row sums Σ_bq(y′, b) = 1 unchanged.
4.4 The weighted norm. (C) needs the bound in ‖B‖²_S = Σ_jΣ_{y∈Λ_j}ℓ_j^{d−2}|B(y)|². Conjugating K := Q(U)𝓔_U − I by S^{1/2} multiplies the (y′, y) block by (ℓ(y′)/ℓ(y))^{(d−2)/2}: ≤ L^{|d−2|/2} for near pairs (scales differ by ≤ 1), and ≤ e^{θ_S d(y, y′)} with θ_S = (|d−2|/2)log L/(RM) for far pairs (each scale change costs a layer width RM; this is the conversion of SOURCES_A1_KERNEL §5, CONFIRMED in A1_A4_VERIFY §1). For RM so large that θ_S ≤ δ_H/4 the far bound keeps decay e^{−δ_Hd/4}.
4.5 Result [P given (KE), (H_Q)]. With m_row^{ms}, m_col^{ms} the moments of C_He^{−δ_Hd}f_ms (row: sup over b; column: η^d/ℓ^d-sum, ×2 by 4.3(c)),
 ε_Q^S := ‖S^{1/2}(Q(U)𝓔_U − I)S^{−1/2}‖ ≤ L^{|d−2|/2}[2α_F√(2m_row^{ms}m_col^{ms}) + 2√2·d·ε″√(m⁰_row m⁰_col)] + 2√2·c_far e^{−δ_HRM/(16L²)}
 ≤ c_Q(d, L)·Mα_0 + c_far′e^{−δ_HRM/(16L²)}.
 Uniform in j, k, volume, {Ω_j}, and regular U: every constant comes from (KE) (independent of {Ω_j} by CMP 99 p. 399 [V]) and from α_F, ε″ (block units).

## 5. Invertibility, the feasible extension, and its energy
5.1 Neumann [P]. If ε_Q^S ≤ 1/2, then Q(U)𝓔_U is invertible on 𝔅 (finite-dimensional) and K_Q := ‖S^{1/2}(Q(U)𝓔_U)^{−1}S^{−1/2}‖ ≤ 1/(1 − ε_Q^S) ≤ 2. Sufficient: c_Q Mα_0 ≤ 1/4 and c_far′e^{−δ_HRM/(16L²)} ≤ 1/4. Balaban's order (d, L; then R, M; then α_0 ≤ a_0/M) allows both.
5.2 Feasible extension [P]. X := (Q(U)𝓔_U)^{−1}B, A := 𝓔_UX. Then Q(U)A = B EXACTLY (full Q(U), Q″ included), A = 0 on Λ_0, and ‖X‖_S ≤ K_Q‖B‖_S. This is the feasibility A1_A4_VERIFY §3 asked for.
5.3 Energy of 𝓔_U [P given (KE) with the gradient part]. Fine covariant difference, ν-direction:
 (D_{U,ν}𝓔_UX)(b) = Σ_y(∇_νE)(b, y)Ad U(Γ_{y→b′})X(y) + Σ_yE(b, y)[Ad U(Γ_{y→b′}) − Ad U(link)^{−1}Ad U(Γ_{y→b})]X(y)/η, b′ = b + ηe_ν (sign conventions only).
 First term: |·| ≤ Σ_y|∇E(b, y)||X(y)| (Ad orthogonal). Second: the bracket is the holonomy of the thin loop Γ_{y→b}·link·Γ_{y→b′}^{−1}; with axial paths from y_− it bounds ≤ |b − y_−|_1/η plaquettes (2.4), so |bracket|/η ≤ 2α_F(|b − y_−|_1/ℓ + 1)/ℓ (near terms; far terms: the trivial bound 2/η is NOT usable here — see [I-c] below). Schur with absolute kernels in the S-weights:
 ‖D_U𝓔_UX‖ ≤ (√K_abs + 2α_F·c_1)‖X‖_S, K_abs := Schur² of C_Hℓ(b)^{−1}e^{−δ_Hd} between (η^d, ℓ^{d−2}) weights, c_1 := first moment. The same for D_U*. So
 K_𝓔 := sup_X (‖D_U𝓔_UX‖² + ‖D_U*𝓔_UX‖²)/‖X‖²_S ≤ 2(√K_abs + 2α_Fc_1)² < ∞, uniform as in 4.5.
 This is cruder than SOURCES_EU §4.5 (absolute values lose the cancellation that gives K_0), but Lemma CT needs only a finite uniform constant, so the flat-frame / 2/3-power step is NOT needed for (C).
5.4 Bound (C) [P given the inputs below]. With G^{−1} ≤ (1 + O(Mα_0))(D_U*D_U + D_UD_U*) + Q*aQ (SOURCES_A1_KERNEL §8; uses R ≤ I and the form version of (3.131) = item S2):
 ⟨B, N^{−1}B⟩ ≤ ⟨A, G^{−1}A⟩ ≤ (1 + O(Mα_0))K_𝓔K_Q²‖B‖²_S + a‖B‖²_μ ≤ K_ext‖B‖²_S, K_ext := (1 + O(Mα_0))K_𝓔K_Q² + a ≤ 4(1 + O(Mα_0))K_𝓔 + a.
 Hence N̂ ≥ c_− := 1/K_ext, which is input (C) of Lemma CT (SOURCES_A1_KERNEL §7–§10).
[I-c] Far terms in 5.3. A far loop (d(b, y) > D) for ADJACENT b, b′ is still thin (length·η area) if the paths Γ_{y→b}, Γ_{y→b′} are nested axial paths — the area bound 2.4 is then |b − y_−|_1/η plaquettes in the WORST local curvature along the strip, which may be in a finer layer (factor L^{2·(layers crossed)}). Against e^{−δ_Hd} this is a loss e^{2 log L·(#layers)} ≤ e^{(2 log L/RM)d}: harmless for RM ≥ 8 log L/δ_H [P-sketch]. Torus-winding paths do not occur here (b, b′ adjacent, same path family). So [I-c] closes under the same RM condition as 4.4.
5.5 Path-rule correction [P]. 2.1's rule (reverse Q-contour on supp q(y, ·), axial elsewhere) can break the thin-loop property of 5.3 at the edge of supp q(y, ·) if the CMP 98 contours are not themselves axial: the loop between a Q-contour and an axial path has area O(ℓ²), and the 1/η of the difference turns it into O(ℓ/η) = O(N), not uniform in k. Fix: use the axial path π for 𝓔_U everywhere. Then the diagonal blocks are no longer exactly 0 but O(α_F) by 2.5 (the Q-leg is the only non-axial leg), which the Neumann bound already covers; nothing else changes. If CMP 98's Γ_{c_−,x} are axial with μ last (the model in §6), the two rules coincide and the diagonal is exactly 0.
