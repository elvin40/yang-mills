## V4. Item (8): plane-wave expansion point
Facts: U_0 = exp(i a cos(px₀) σ₃/2) on direction-1 links has gradient A^{(1)}(U_0) = O(a p²) (lattice Maxwell on a transverse wave), so it is not a fiber stationary point; ΔD = O(a p²) ✓.
Argument: Γ_1(U) := log det G − ½ log|det Bord(U)| with the plain Hessian is a gauge-invariant function on all of link space (Δ, D, Q̃ transform by Ad; NUMERICS §4 tests 1e−12). At U_1 it equals Balaban's one-loop value except the −⟨J, C^{(2)}⟩ term. (a) Γ_1(U_0) − Γ_1(U_1) = ⟨Γ_1′, B*⟩ + O(B*²). Γ_1′ at a smooth abelian background is a gauge-covariant vector, odd dimension, so ≥ dim 3 (D_μF_{μν}): O(a p²); a constant abelian A is pure gauge, so the kernel vanishes at p = 0. B* = O(a p²) × (fiber propagator) ✓. Product O(a²p⁴). (b) J-term: J = O(a p²); its pairing with the a-linear part of ⟨C^{(2)}⟩ is O(a²p³) at worst and O(a²p⁴) by reflection parity. So w(p) error = O(a²p⁴) and β(p) error = O(p²): the p → 0 limit (β_1) is unaffected. Agree, at sketch level (not a proof).
Correction: the fiber propagator has range L, so B* = O(a p² L²) and the small parameter is Lp, not p. The error is O(p²L²) in β(p).
Effect on NUMERICS §6: L = 2, 3 values come from p → 0 quadratic fits, so they are unaffected. L = 4 (0.757) and the two-level values (1.148, 0.967) are single p = 0.2 points, Lp = 0.8, no extrapolation. Their total O(p²) bias is bounded by the observed slope: L = 3 gives β(0.2) − β(0) = 0.005; scaled by (4/3)² ≈ 0.009 at L = 4. The defect is one part of this. Small against the 0.093 L-difference; negligible against the two-level grid error (0.18 between Ng = 4 and 6). NUMERICS §6 should label L = 4 and two-level numbers "p = 0.2, not extrapolated, O((Lp)²) bias ≈ 1e−2".
Grade (8): CONFIRMED with the L² correction.
