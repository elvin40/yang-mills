## 3. Free case: K_0(d) [N, numerics/k0_d.py, 1.7 s on Mac]
Formula [P]. At U = 1 with Feynman-gauge form ⟨A, M_0A⟩ = Σ_μ⟨A_μ, −Δ_ηA_μ⟩ (R = I; R ≤ I only lowers the form), the minimum of ⟨A, −ΔA⟩ subject to QA = B is ⟨B, (QΔ^{−1}Q*)^{−1}B⟩. In momentum space QΔ^{−1}Q* is multiplication by T_μ(p′) = Σ_l |u|²|v_μ|²/Δ (p′ + l) (KAPPA_D symbols, N = L^k; Q_k = composition of k equal-weight one-step corridors has symbol u_kv_{μ,k} by telescoping of geometric sums). So K_0 = sup_{p′,μ} 1/T_μ(p′) = 1/inf T = κ_d − 1 at a = 1.
Self-check [N]. Dense real-space minimum-energy extension on a periodic d = 2 lattice (fine (N·L_u)², spacing 1/N, corridor weights N^{−(d+1)}, p′ = 0 mode removed) equals 1/min_{p′≠0} T to 1e−8: N = 3, L_u = 4: 48.19834711 both; N = 3, L_u = 3: 19.44 both; N = 5, L_u = 3: 22.18934911 both. This checks the momentum formula independently of the symbol code.
Numbers [N] (minimum at p′ = (π, …, π) for every N, grid + Nelder–Mead):
| d | N = 3 | N = 5 | N = 13 | N = ∞ |
| 4 | 103.248 | 146.731 | 185.643 | 195.188 |
| 3 | 75.310 | 102.108 | 122.438 | 126.853 |
N = ∞: s → 4/q², Δ → |q|², q ∈ π(2Z + 1)^d, truncation |m| ≤ M: d = 4 M = 20/40/60 → 195.1949/195.1885/195.1878 (tail O(1/M); KAPPA_D quotes κ_4 = 196.188 → 195.188); d = 3 converged to 126.8533 at M = 80. Matches κ_d − 1 from KAPPA_D (κ_4 − 1 = 195.19, κ_3 − 1 = 126.85) [N].
K_0 increases with N = L^k, so sup_k K_0 = the N = ∞ value: K_0(4) = 195.19, K_0(3) = 126.85. The crude CDC §3.2 bound dπ²(π/2)^{4d} = 5.4e4 (d = 4) is 280 times too large.
Meaning. The worst B is the staggered mode p′ = (π, …, π): B alternates sign from block to block. K_0 is a property of the cost of a checkerboard; the cost of smooth B is small (T → ∞ as p′ → 0).

## 4. Background case: explicit covariant extension [P-sketch unless tagged]
4.0 Units and the plaquette bound. Unit-lattice units (L^kη = 1 on Λ ⊂ Λ_k), fine spacing η = 1/N. In the gauge of (3.35), U = e^{iηA} with |A|, |∇^ηA| ≤ O(1)Mα_0. BCH on the four bonds of a fine plaquette: U(∂p) = exp(iη²F_p + O(η²|A|²)), F_p = ∇_μA_ν − ∇_νA_μ, so |U(∂p) − 1| ≤ α_F η², α_F := 2·O(1)Mα_0(1 + O(Mα_0)) [P]. This is CMP 98 (52) |U(∂p) − 1| < α_0η² with α_0 → α_F; it is gauge-invariant, so it holds on every plaquette of the regular region, not only inside one cube.
Lattice Stokes [P]. If a closed lattice loop ℓ bounds a lattice surface S of n plaquettes, |U(ℓ) − 1| ≤ Σ_{p∈S}|U(∂p) − 1| ≤ α_F·Area(S) (Area in unit units = nη²). Proof: write U(ℓ) as an ordered product of lassoes g_i U(∂p_i)g_i^{−1}; for unitary factors |Πh_i − 1| ≤ Σ|h_i − 1| and conjugation keeps |h − 1|. Note: transport along an open path of unit length is NOT close to 1 (|A| ~ Mα_0 is gauge-dependent and M²α_0 across a cube need not be small); only loop holonomies are small.
4.1 Construction. Let E_0 be the free minimal extension (A_0 = E_0B, energy ⟨B, (QΔ^{−1}Q*)^{−1}B⟩ ≤ K_0‖B‖², §3). It is a real scalar kernel E_0(y, c) per component, exponentially decaying in |y − c| ([N] §4.4). For each fine bond y and block c fix a path Γ_{c→y} on the fine lattice (block base point c_− to y_−; axial: coordinates in fixed order). Define
 (𝓔_U c)(y) := Σ_c E_0(y, c)·Ad U(Γ_{c→y})·c(c),
and the extension A := 𝓔_U (Q(U)𝓔_U)^{−1}B. Then Q(U)A = B exactly, whenever ‖Q(U)𝓔_U − I‖ < 1.
4.2 The brief's "exact by transport-and-back" claim is false [P]. Q(U)𝓔_U(c′, c) = Σ_y w_{c′}(y)E_0(y, c)Ad U(Γ_{c′←y}Γ_{c→y}) (+ the Q″ part). For c = c′ with Γ_{c→y} the reverse of Q's contour, the transport is the identity. But for c ≠ c′ the free identity Σ_y w_{c′}(y)E_0(y, c) = 0 holds by CANCELLATION (E_0 changes sign), and the covariant weights Ad U(c → y → c′) differ from y to y. So the off-diagonal terms do not cancel. A local profile supported where only one corridor sees it would make Q(U)A = B exact, but such a region is one slice of N^{d−1} fine bonds per block (corridors of c and c ± e_μ overlap on all other μ-offsets), and a field on one slice has energy ∝ N³ → ∞ as k → ∞ [P: weight 1/N per slice, jump η^{−1} across it]. So the inverse correction (Q(U)𝓔_U)^{−1} is required.
4.3 Constraint error [P-sketch]. Because Σ_y w_{c′}(y)E_0(y, c) = δ_{cc′}, any fixed reference transport τ_{c→c′} can be subtracted: |(Q_U𝓔_U − I)(c′, c)| ≤ Σ_y |w_{c′}(y)||E_0(y, c)|·|Ad U(loop c → y → c′ → c) − 1| ≤ α_F Σ_y |w_{c′}(y)E_0(y, c)|·Area(c, y, c′). Area of the axial triangle ≤ d·|y − c|·|y − c′| ≤ d(|y − c| + 1)·(|y − c|+ |c − c′|)-type, and w_{c′} is supported within distance 2 of c′. Schur test: ε_Q ≤ α_F·c_St·ν_2 + ε_Q″, with ν_j := Σ_y η^d|E_0(y, 0)|(1 + |y|)^j (a free-kernel moment) and c_St ≤ 4d (path/area bookkeeping, [I] not optimized). ε_Q″ = the CMP 98 (124) remainder, O(L²α_0) per step by (139); for the k-step composition the constant "independent of η" (CMP 98 p. 37, (141)) [R, constant not read].

4.4 Free-kernel moments [N, k0_d.py kernel_moments: FFT on periodic (N·L_u)^d, checks QA = B to 1e−9 and energy = ⟨B, X⟩]. Single block source B = δ_0, d = 4, moments about the corridor centre r:
 N = 3, L_u = 10: energy 28.59; Σ_y η^d|E_0|r^j (j = 0, 1, 2) = 5.16, 10.72, 41.90; Σ η^d|∇E_0|r^j = 23.80, 32.62, 58.06.
 N = 5, L_u = 8: energy 35.35; |E_0|: 5.63, 10.30, 31.01; |∇E_0|: 28.28, 39.62, 70.61.
 Decay: max|E_0| on unit shells r ∈ [R, R+1): 2.28, 0.57, 0.19, 0.06 (N = 5), a factor ≈ 3–4 per unit, δ ≈ 1.2. The j = 2 moments move with L_u (finite volume), so they are indicative only [N, not converged in L_u].
 Write ν_j, γ_j for Σ η^d|E_0|(1 + r)^j and Σ η^d|∇E_0|(1 + r)^j. At N = 5: ν_2 ≈ 57, γ_0 ≈ 28, γ_1 ≈ 68, γ_2 ≈ 178.
4.5 Energy of 𝓔_Uc [P-sketch]. Covariant difference: (D_ν𝓔_Uc)(y) = 𝓖c + 𝓡c, with 𝓖c(y) = Σ_c (∇_νE_0)(y, c)Ad U(Γ_{c→y})c(c), and 𝓡 from the thin loop Γ_{c→y}·(y, y + ηe_ν)·Γ_{c→y+ηe_ν}^{−1}, whose axial spanning surface has area ≤ η(d|y − c| + 1). With the 1/η of the difference: |𝓡c(y)| ≤ α_F Σ_c |E_0(y + ηe_ν, c)|(d|y − c| + 1)|c(c)|, so ‖𝓡‖ ≤ α_F·d·ν_1 (Schur; [I] the c-sum at fixed y is replaced by the η^d y-sum at fixed c, equal up to lattice-sum versus integral factors). The D_U* (gauge-fixing) part has the same form with a divergence and the same bound; R(U) ≤ I only lowers it [V CMP 99 p. 394: R an orthogonal projection].
 Main term — the hard part. ‖𝓖c‖² = ⟨c, G^U c⟩, G^U(c, c′) = Σ_y η^d ∇E_0(y, c)·∇E_0(y, c′)·Ad U(c′ → y → c). If the transports were a pure gauge, G^U would be unitarily equivalent to the free G and ‖G^U‖ ≤ K_0. They are not, and an entrywise comparison fails: the worst free mode is the checkerboard p′ = (π, …, π), and the kernel |G| (absolute values) has a larger norm than G. So one needs a flat frame. On a patch of radius R, the axial frame from the patch centre is flat up to loops of area ≤ R·(|c − c′| + |y − c|), i.e. error α_F·R per unit of kernel moment. IMS localization (Σ_iφ_i² = 1, |∇φ_i| ≤ 1/R, overlap n_d ≤ 2^d) costs the double commutator ≤ n_d·Γ_2/R². Result:
 ‖G^U‖ ≤ K_0 + α_F·d·(R·Γ_1 + Γ_2) + n_dΓ_2/R², Γ_j := sup_c Σ_{c′}Σ_y η^d|∇E_0(y, c)||∇E_0(y, c′)|(|y − c| + |y − c′|)^j ≤ 2^jγ_0γ_j [I: lattice-sum factor].
 Best R ∝ α_F^{−1/3} gives ‖G^U‖ ≤ K_0 + C_G(d)α_F^{2/3}, C_G = 3(dΓ_1)^{2/3}(n_dΓ_2/2)^{1/3}·2^{−1/3}-type [P-sketch, constant not optimized].
4.6 Assembly. With ε_Q from 4.3 and K from 4.5:
 √K ≤ [√(K_0 + C_Gα_F^{2/3} + dα_FΓ_2) + dα_Fν_1]/(1 − ε_Q),  α_F ≤ 20Mα_0(1 + O(Mα_0)) (O(1) ≤ 10, CMP 99 p. 396 [V]).
 So K ≤ K_0(1 + c_{2/3}(Mα_0)^{2/3} + c_1Mα_0) [P-sketch]. Plugging the d = 4, N = 5 moments (Γ_1 ≈ 2γ_0γ_1 ≈ 3.8e3, Γ_2 ≈ 4γ_0γ_2 ≈ 2.0e4, n_4 = 16) gives C_G ≈ 7.9e4, so c_{2/3} ≈ (C_G/K_0)·20^{2/3} ≈ 3e3, i.e. K ≤ 1.1K_0 needs Mα_0 ≲ 2e−7 [N, crude; all Schur steps lossy]. This is "O(1)Mα_0 sufficiently small" in Balaban's sense, but the constant is large.
 The LINEAR form K ≤ K_0(1 + c·Mα_0) asked in the brief is NOT proved here [I]. It needs the flat-frame step without patching: a gauge-covariant (non-abelian, lattice) version of the magnetic Weyl calculus / Peierls-phase lemma (abelian constant-field analogues: Nenciu; Iftimie–Măntoiu–Purice, where Op^B(a) = Op(a) + O(B) in norm). Plausible, not checked. For the use in SOURCES_CDC (any K = K(d) with K → K_0 as Mα_0 → 0) the 2/3-power bound is sufficient.
