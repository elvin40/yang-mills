## 1. CMP 109 pp. 261–266: what the inductive assumption says, and the global objects of the step [V, text layer; PDF page = journal page − 248]
1.1 p. 261 (1.7) [V]: "The function E^{(j)}(g_{j−1}, U_j) is a result of an integration in the j-th step, after a subtraction of the previous action evaluated at U_j. We assume that it has the representation [(1.7) Σ_{X∈D_j}]. Again, the term corresponding to a domain X depends on U_j restricted to X. We can assume that this representation holds for the functions E^{(j)} in (1.3) and (1.6), because the expansion of the log Z^{(j−1)}(U_j) constructed in [16], implies, that we can represent this term in the form (1.7)."
1.2 p. 261 (1.9) / p. 262 [V]: E^{(j)}(X, g_{j−1}, U, J) are "functions defined on larger spaces of regular gauge field configurations", analytic on U^c_j(X, α_0, α_1); "U is defined at bonds of X … J is also defined at bonds of X". So each activity is, by its stated domain, a function of configurations on X alone. Condition (iv) of the space (p. 262) builds axial-gauge maps U_n(M′(U)) from a sequence of domains {Ω_n} constructed from X itself ("We consider X as Ω_0"). So the domain of the function is intrinsic to X [V]. This does not say the function is the same for the torus and Z^4; it says nothing about how the function was produced [I, agrees with A15_WHOLE_VERIFY V2].
1.3 p. 264 [V]: "Now we take a limit of these functions as T^{(j+1)} ↗ Z^d. This limit exists by the localized representation (1.7)." No more is printed.
1.4 Global objects of the step, pp. 265–266 [V]:
 (G-a) the critical configuration V^{(k)}(W), the minimum of V ↦ G(V) + A(U_k(V)) on {V : V̄ = W}, related to the minimal configuration U_{k+1}(W) (CMP 102 variational problem) — a global (whole-torus) nonlinear problem;
 (G-b) the axial gauge Ax_k(T^{(k)}, U_{k+1}) and the axial→Landau gauge transformation u_k of [14], with exp iηH_k(B′) = U_k u_k^{−1};
 (G-c) the linear maps H_{1,k}, A_{1,k}, D_k = C^{(2)} + D_3, the operator Δ_1 of (2.7) ("(3.127), (3.128) [13]");
 (G-d) the gauge-fixing expansion (2.5), G_3 "localized in blocks of the lattice T^{(k)}" (strictly local);
 (G-e) after (2.9): the δ-function elimination B′ = CB, "C is the operator determined by the configuration V^{(k)}", and the Gaussian measure with covariance built from C*Δ_kC (p. 268).
 Each of (G-a), (G-b), (G-c), (G-e) is a global object on T^{(k)}: on the torus its kernel is the torus kernel. None is strictly finite-range. So E^{(k+1)}(X) is local only through the Sect. 3 localization operations. Section 2 below reads them.

2.5 Reading [I, from 2.3–2.4]. CMP 109 Sects. 3–4 are a bound-and-book procedure. Each split global = local + remainder is an exact algebraic identity; the remainder is only bounded ("exponentially small", "irrelevant"). The remainder still contains the global (torus) objects H_k(B′), δH_j/δB, U_{k+1}. CMP 109 never writes the remainder in the form (1.7). It defers that to a "final localization" "in a general case" (p. 270, p. 276). So CMP 109 alone does not determine whether E^{(k+1)}(X) is volume-intrinsic. The answer depends on the final localization. Section 3 reads it (CMP 116 Sect. 1, the s-rule).
