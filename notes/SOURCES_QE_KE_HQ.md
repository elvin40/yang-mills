## 2. Task (A): (KE′) at all scales, as a fallback for the corridor reading
Notation (one step, level spacing 1, coarse spacing L). Q_S := straight-line average (CMP 95 (1.11) = CMP 98 (125) at V_0 = 1). Q_C := corridor (CMP 95 (1.8) = CMP 98 (14)). Λ: fine 1-forms → coarse 0-forms, (ΛA)(Y) := Σ_{x∈B(Y)}L^{−d}A(Γ_{Y,x}). P: block average of a 0-form, S: sampling at block points, d: unnormalized lattice difference.
2.1 (A1) one step [P from (14), (125); V via EU_VERIFY §3 recomputation of (119)–(120)]. Since A(Γ_{x(c),c_+}) = −A(Γ_{c_+,x(c)}) and x ↦ x(c) maps B(c_−) onto B(c_+):
 Q_S = Q_C + L^{−1}dΛ, i.e. (Q_SA)(c) = (Q_CA)(c) + L^{−1}[(ΛA)(c_+) − (ΛA)(c_−)].
 Linear gauge covariance [P]: Q_S(dφ) = L^{−1}d(Pφ), Q_C(dφ) = L^{−1}d(Sφ), Λ(dφ) = Pφ − Sφ (consistent with the identity).
2.2 (A2) j steps [P]. Let Q_j^S, Q_j^C be the j-fold compositions (Q_j^S = CMP 95 (1.18) by straight-line telescoping [P, N]). Write Q_S∘Q_j^S − Q_C∘Q_j^C = Q_S(Q_j^S − Q_j^C) + (Q_S − Q_C)Q_j^C. With Q_j^S − Q_j^C = L^{−1}dΛ̃_j and 2.1:
 Q_{j+1}^S − Q_{j+1}^C = L^{−1}d Λ̃_{j+1}, Λ̃_{j+1} := L^{−1}PΛ̃_j + Λ^{(j+1)}Q_j^C, Λ̃_1 = Λ^{(1)}.
 Closed form: Λ̃_j = Σ_{i=1}^{j} L^{−(j−i)}P^{j−i}Λ^{(i)}Q_{i−1}^C (P^{j−i} = block average from level i to level j).
 Answer to "telescope or accumulate": the gradient terms ACCUMULATE (a sum over all levels i ≤ j), but the sum is one exact gradient on the scale-j lattice. Weights: L^{−(j−i)} from the 1-form normalization; Λ^{(i)} acts on the level-(i−1) field Q_{i−1}^C A. In fine-lattice terms, (Λ̃_jA)(y) = Σ_b w_j(y, b)A_b with w_j supported in B^j(y) ∪ (one fine layer of neighbours) and Σ_b|w_j(y, b)| ≤ c(d)·Σ_i L^{−(j−i)}·(level-i contour length ≤ dL) ≤ c(d)L²/(L − 1) in units of the level-j spacing [P]: Λ^{(i)} has total weight ≤ d·L (contours of length ≤ dL), Q_C and P have total weight 1 per row (Σq = 1 incl. the corridor legs: 1 + 2·O(d)/L ≤ c(d)), so the series is geometric.
 The other order gives an equivalent form Λ̃′_{j+1} = Λ^{(j+1)}Q_j^S + L^{−1}SΛ̃′_j; both are exact (same dΛ̃).
 [N] numerics/qe_inv/ke_hq_identities.py (d = 2, L = 3, axial Γ, periodic, 0.1 s): direct corridor sum vs Q_S − L^{−1}dΛ: 2e−16; Q_SQ_S = straight N = L² average: 3e−17; Q_2^S − Q_2^C − L^{−1}dΛ̃_2: 1e−16 (both orders); j = 3 via the recursion: 1e−17.
2.3 (A3) the repair at level j, one layer [P]. Suppose H satisfies Q_j^C H = I (any H, minimizer or not). Put 𝓔_j := H + dψ_j. Since Q_j^S(dψ) = L^{−j}d(P_jψ) (P_j = scale-j block average; iterate 2.1), the condition Q_j^S𝓔_j = I reads d[L^{−1}Λ̃_jH + L^{−j}P_jψ_j] = 0 on the constrained bonds. Sufficient LOCAL linear equation:
 P_jψ_j(y) = −L^{j−1}(Λ̃_jH)(y) for every scale-j block point y   (block averages of ψ = −λ_H, in level-j normalization).
 Solution: ψ_j := −Σ_y L^{j−1}(Λ̃_jH)(y)·φ_y, φ_y a fixed smooth bump on B^j(y) (rescaled from one profile), P_jφ_y = δ_{yy′}, φ_y = 0 on the boundary sites of B^j(y), |∇^kφ_y| ≤ c_k(d)ℓ_j^{−k}. Kernel: ψ_j(·, c) at x ∈ B^j(y) is a combination of H(b, c), b in B^j(y) and its one-layer neighbourhood, with total weight ≤ c(d)L²/(L − 1)·ℓ_j (line integrals). Hence, in the (KE) normalization E(b, c) = (L^{j(c)}η)^dH(b, c):
 |dψ_j(b, c)| ≤ c_ψ C_H e^{−δ_H(d(b,c) − c(d))}, ℓ(b)|∇dψ_j(b, c)| ≤ c_ψ C_H e^{−δ_H(d(b,c) − c(d))}, c_ψ = c(d)L²/(L − 1)·max(c_1, c_2)(bump).
 So 𝓔_j obeys (2.151) with C_H → C_H(1 + c_ψe^{c(d)δ_H}) and the same rate δ_H [P given (KE) for H]. [N] the same script: P_jψ = −L^{j−1}Λ̃_j (j = 2) to 4e−16 and Q_2^S(A + dψ) = Q_2^C A to 1e−16 with a sin² bump.

2.4 (A4) interfaces and Λ_0 for the fallback.
 Λ_0 [P]. The bumps vanish on block-boundary sites, so dψ lives on bonds with an endpoint inside some B^j(y) ⊂ Ω_1. Λ_0 (bonds with no endpoint in Ω_1) never meets it: 𝓔_j = 0 on Λ_0 if H = 0 there. No defect.
 Layer interfaces [P-sketch: defect, not closed]. Take ψ := Σ_jψ_j, ψ_j from 2.3 for the block points of Λ_j. A bond c″ ∈ Λ_{j+1} with c″_+ outside Ω_{j+1} (CMP 96 (2.3): bond sets include bonds with one endpoint in the set) has B^{j+1}(c″_+) = a union of L^d scale-j blocks that are block points of Λ_j. There P_{j+1}ψ = L^{−d}Σ(sub-block averages) is already FIXED by the layer-j equations, while the layer-(j+1) equation asks for a value built from Λ̃_{j+1}H, a different potential. Exactness needs the potentials of adjacent layers to agree on every cycle of constrained bonds that passes through two such outer endpoints; for generic H they do not. The free part of ψ (P_jψ = 0 on all constrained blocks) cannot help, because P_{j+1} of it is also 0. So a pure-gauge repair of a corridor-constrained H has an O(1)-relative defect on the interface rows (distance O(1) in block units from ∂Ω_{j+1}), like QE_INV 4.1, and Neumann cannot absorb it.
 Conclusion of (A). The fallback closes (KE′) inside each layer at every scale j and at Λ_0, but NOT across layer interfaces. The only exact multiscale route is the minimizer constrained by the straight-line Q_j itself — and §1 shows that this is Balaban's H of CMP 96 Cor. 2.8. So (KE′) is PROVED by citation [V] on the main line; the fallback is not needed and would not suffice at interfaces.
