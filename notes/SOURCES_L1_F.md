## 2. Lemma J — threshold derivative of a cutoff on a star-shaped level set [P]

Setting. x ∈ R^n is a chart variable of one integration bond; w collects all other variables. F(x, w) ≥ 0 is measurable. The cutoff is 1{ψ(x, w) < t}, t > 0.
(J1) Radial graph. For fixed w there is a centre x_0(w) such that, for every unit vector ω (Euclidean norm on R^n), r ↦ ψ(x_0 + rω, w) is C¹ on [0, r_*], ψ(x_0, w) = 0, and ∂_rψ ≥ a > 0 there. Put T := a·r_*.
Lemma J. Under (J1), for 0 < t < T:
 d/dt ∫_{R^n} 1{ψ(x, w) < t}F(x, w) dx = ∫_{S^{n−1}} F(x_0 + R_t(ω)ω, w) R_t(ω)^{n−1}(∂_rψ)^{−1}|_{r=R_t(ω)} dω,
where R_t(ω) ∈ (0, t/a] is the unique root of ψ(x_0 + rω, w) = t on [0, r_*], provided {ψ < t} ∩ {|x − x_0| > r_*} = ∅ (no far component). Hence
 |d/dt ∫1{ψ < t}F dx| ≤ |S^{n−1}|a^{−n}t^{n−1}·sup_{ψ(·,w)=t, |x−x_0|≤t/a}F(·, w).     (J.1)
Proof. Polar coordinates x = x_0 + rω give dx = r^{n−1}dr dω. By (J1), ψ(x_0 + rω) ≥ ar, so the root R_t(ω) exists, is unique, and R_t ≤ t/a < r_*; also {ψ < t} = {r < R_t(ω)} by the no-far-component condition. So ∫1{ψ < t}F dx = ∫_{S^{n−1}}∫_0^{R_t(ω)}F r^{n−1}dr dω. By the implicit function theorem ∂_tR_t = 1/∂_rψ(R_t) ≤ 1/a. Differentiate under the ω-integral (dominated: integrand ≤ sup F·(t/a)^{n−1}/a). ∎
Integrated form. Integrate (J.1) over w against any w-measure: the derivative of the full integral is ≤ |S^{n−1}|a^{−n}t^{n−1}∫dw sup_{ψ(·,w)=t}F(·, w). This is the "sup-norm F" form that B15 §2.1 used (setting A: Balaban's pointwise large-field bound gives the decay on the level set).
Corollary J-a (norm balls) [P]. ψ(x, w) = ‖x − x_0(w)‖ for any norm ‖·‖ on R^n with c_N|x| ≤ ‖x‖ ≤ C_N|x|: (J1) holds with a = c_N, r_* = ∞. This covers the per-bond cuts |A_k(b)| < δ_k (F4), |B′(b)| < ε_1 (F2), |B′(b)| < δ′_k (F8), and |(1/i)log V′(b)| < M_0ε_k (F9) in Lie-algebra coordinates, whatever matrix norm Balaban's |·| is (Hilbert–Schmidt gives c_N = C_N = 1).
Corollary J-b (group translates) [P]. Let u ∈ G be the integration link, with Haar measure, and ψ = |uW − 1| or |Wu − 1|, with W ∈ G independent of u and |·| an operator-type norm with |e^{iX} − 1| = 2 sin(‖X‖/2) on ‖X‖ ≤ π (‖·‖ the operator norm on the Lie algebra). Use the chart u = exp(iX)W^{−1}. Right invariance of Haar measure gives du = j(X)dX with j the exponential-chart density, j(X) = Π_{α>0}(sin(α(X)/2)/(α(X)/2))² ∈ [j_−, 1] for ‖X‖ ≤ 1, j_− := (sin ½/½)^{2·#roots}. In this chart ψ = 2 sin(‖X‖/2): r ↦ ψ(rω) has derivative ‖ω‖cos(r‖ω‖/2) ≥ c_N cos(½) for r‖ω‖ ≤ 1. So (J1) holds with x_0 = 0, a = c_N cos ½ ≥ 0.877c_N, r_* = 1/C_N, and T = 0.877c_N/C_N. No far component for t ≤ ½: ψ ≥ (2/π)‖X‖ on ‖X‖ ≤ π, so ψ < ½ forces ‖X‖ < π/4. The Haar density factor j ≤ 1 is absorbed into F. Covers (1.27) with W = (V_Z^{(j)}(b))^{−1} (F7: V_Z is a background function) and (1.29) with W = 1, for 2δ′_j, ε_j ≤ ½.
Corollary J-c (near-isometric maps) [P]. ψ = |Φ(x, w)| with Φ(x_0 + y, w) = A(w)y + N(y, w), A(w) a Euclidean isometry, |D_yN| ≤ e ≤ 1/4 on |y| ≤ r_*. Then ∂_rψ ≥ (1 − 2e − e²)/(1 + e) ≥ 1 − 3e and ψ ≥ (1 − e)r, so (J1) holds with a = 1 − 3e. Proof: Φ(x_0 + rω) = r(Aω + η), |η| ≤ e; ∂_rΦ = Aω + E, |E| ≤ e; ∂_r|Φ| = ⟨Aω + η, Aω + E⟩/|Aω + η| ≥ (1 − |η| − |E| − |η||E|)/(1 + e) ≥ (1 − 2e − e²)/(1 + e) ≥ 1 − 3e, since (1 − 3e)(1 + e) = 1 − 2e − 3e². ∎

(i) It gives no Gaussian decay by itself; the decay must come from a pointwise bound of F on the level set (setting A of B15), or from a marginal computation when the level set is round in a coordinate of the Gaussian (setting B, G3_N2 2.4). For Corollaries J-a and J-b with x_0(w) ≡ 0 the level set is round (or a fixed norm sphere) in a fixed coordinate, so the setting-B marginal argument of G3_N2 2.4–2.5 applies verbatim with |S^{n−1}|r^{n−1} replaced by the norm-sphere area n·vol{‖x‖ < 1}t^{n−1}. (ii) It does not cover cutoffs whose variable depends on every integration link through a composite map with no printed lower bound on its one-link derivative (F8 (1.88), χ_{h,1/2}): (J1) needs a > 0 for some single link, and for U_{h,□}((1, V_h), ∂p) the derivative in one V_h(b) is a kernel of the operator H_{h,□} (CMP 122 I (1.30)) whose lower bound is not printed.
