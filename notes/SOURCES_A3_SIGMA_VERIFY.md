## V4. CMP 99 Sect. C: (3.93), (3.107), (3.108), Thm 3.11 [V image p. 416 at 130 dpi; text l. 1055–1085, 1215–1226, 1878–1890]
- (3.107) verbatim: "G = Σ_ω R_0(X_0)R_{α_1}(X_1)···R_{α_n}(X_n), the sum is over walks ω = ((0,X_0),(α_1,X_1),…,(α_n,X_n)) satisfying X_{i−1} ∩ X_i ≠ ∅ ... depends on configuration U restricted to X̃_0^5 ∪ X̃_1^5 ∪ … ∪ X̃_n^5". The expanded object is the propagator G (an inverse), not a precision. CONFIRMED.
- (3.108) verbatim: "|(R_0(X_0)R_{α_1}(X_1)···R_{α_n}(X_n)J)(x)| ≤ O(1)(L^jη)²O(M^{−1/2})^{|ω|}·M^{−½|ω|}e^{−(1/2)δ_0d(ω,y,y′)}|J|, x∈Δ(y), y∈Λ_j, supp J ⊂ Δ(y′)". Then: "From (3.108) it follows that the expansion (3.107) is convergent in all norms". Differences from CMP 116 (1.7): exponent ½δ_0 (not δ_0), M (CMP 116 writes M_1, the small-cube size of that construction). Absolute convergence: asserted from (3.108) [R]; walk counting is the standard "O(M^{−1/2}) controls the sum" (Cor. 3.8: "We will use the factor O(M^{−1/2}) to control the sum over random walks ω"). (W) is therefore [R], same status as the author states, but at CMP 99, not CMP 109.
- d(ω,y,y′), (3.93) verbatim: "d(ω,y,y′) = inf_{(y_1,…,y_n)} {d(y,y_1) + d(y_1,y_2) + ··· + d(y_{n−1},y_n) + d(y_n,y′)}, the infimum is taken over all sequences ... of points y_i ∈ □_i". For tree-shaped expansions (Sect. D, l. 1884): "d(ω,y,y′) is now a length of a shortest tree intersecting all domains X_i in ω".
- Consequence for SOURCES 2.3: d is the length of a path y → (point in each domain) → y′. If y, y′ lie in Z_0 and some domain X_j has dist(X_j, Z_0) > ⅔M, then d ≥ 2·⅔M = (4/3)M for chains, and ≥ ⅔M for trees that contain y. So "d(ω,b,b′) ≥ ⅔M on W_σ" is CONFIRMED and conservative; the [I] becomes [V] from (3.93).
- Caveat on 2.3: membership in W_σ uses X̃_j^5 (5-collar of M_1-cubes), but any walk of length ≥ 1 has a domain X_1 with dist(X_1, Z_0) > ⅔M (p. 13), so length ≥ 1 already gives d ≥ ⅔M. Only the zero-length walk needs the interior reading (V2). Fine.
- Thm 3.11 verbatim: "It [G] is a symmetric and invertible operator". Symmetry is stated for the full sum G, not per walk. The single-walk terms start at R_0(X_0), so they are not reversal-symmetric on the page. SOURCES 4.4 is correct that (S_s) is not visible.
- Constant in the exponent: with (3.108)'s ½δ_0 and d ≥ (4/3)M one gets e^{−½δ_0d} ≤ e^{−⅓δ_0M}e^{−¼δ_0|y−y′|}. So the factor e^{−⅓δ_0M} is right with the CMP 99 normalization; the off-diagonal decay is ¼δ_0 there, not ½δ_0. δ_0 is a paper-dependent constant. Not load-bearing: η_M ∝ e^{−cδ_0M}, c > 0, is all that §3–§4 use.

## V5. Algebra checks [P, re-derived independently]
- Domination: D(s) = Σ_ω(s^ω − 1)T_ω = −Σ_{W_σ}(1 − s^ω)T_ω; s^ω ∈ [0,1] ⇒ 0 ≤ 1 − s^ω ≤ 1; blockwise ‖D(s)(b,b′)‖ ≤ K(b,b′). CONFIRMED. The author's 2.5 point (absolute majorant, not the signed (2.16) bound) is right.
- Schur: K(b,b′) ≤ ε_W e^{−c|b−b′|} is symmetric in (b,b′), so row and column sums agree; Σ_{x∈Z^d} e^{−c|x|} ≤ coth(c/(2√d))^d. The extra factor d in S_d is a harmless overcount (d bond directions). CONFIRMED.
- B_W caveat [new]: in the p. 13 construction X_0 is the large domain with X̃_0^5 = Z̃_0, so the number of X_1 with X_1 ∩ X_0 ≠ ∅ grows with |∂Z_0|. The sum over X_1 is then controlled by part of e^{−δ_0d} (CMP 99 Cor. 3.8 does this: "We use part of the exponentials to control the sum over y's"), not by O(M^{−1/2})^{|ω|} alone. Uniformity of B_W in Z_0 holds with a smaller δ-constant; it is [R] to Balaban's p. 13 construction (not detailed anywhere). Affects constants only.
- Form bound 3.1: C_1 = (Z_0AZ_0)^{−1}, γ_0 ≤ Z_0AZ_0 ≤ γ_1 (compression) ⇒ spec C_1 ⊂ [γ_1^{−1}, γ_0^{−1}]; ⟨v,C_sv⟩ ≥ (γ_1^{−1} − η_M)‖v‖². CONFIRMED.
- 4.1 symmetric: λ_min(C_s^{−1}) ≥ 1/(γ_0^{−1} + η) = γ_0/(1 + γ_0η); ε = γ_0²η/(1 + γ_0η); γ_0η ≤ γ_1η ≤ ½ ⇒ ε ≤ γ_0/3; λ_max(C_s^{−1}) ≤ (γ_1^{−1} − η)^{−1} ≤ 2γ_1. CONFIRMED.
- 4.2 resolvent: C_s^{−1}(C_s − C_1)C_1^{−1} = C_1^{−1} − C_s^{−1}. ✓. ‖C_1^{−1}‖ ≤ γ_1; ‖C_s^{−1}‖ ≤ (γ_1^{−1} − η)^{−1} ≤ 2γ_1 without symmetry (coercive ⇒ ‖C_sv‖ ≥ c‖v‖; finite volume ⇒ invertible). So ‖R(s)‖ ≤ 2γ_1²η_M. CONFIRMED.
- 4.3(iii) CORRECTED (too weak). The resolvent bound already gives, with no symmetry: ⟨v, C_s^{−1}v⟩ = ⟨v, C_1^{−1}v⟩ − ⟨v, R(s)v⟩ ≥ (γ_0 − 2γ_1²η_M)‖v‖². So λ_min(Sym C_s^{−1}) ≥ γ_0 − 2γ_1²η_M, ≥ γ_0/2 if η_M ≤ γ_0/(4γ_1²). This is the "γ_0 − ε" form with ε = 2γ_1²η_M, worse constant than 4.1 (γ_0²η_M) but no (S_s). Note also: Balaban's (2.15) uses the measure through the PRECISION, "dμ_{(Re C^{(k)}(Z_0,σ)^{−1})^{−1}}", so the relevant object is Sym/Re of C_s^{−1}, not Sym C_s. SOURCES 4.3(ii) "a real Gaussian only sees Sym C_s" is the characteristic-function convention; Balaban's convention is the density one. The new bound covers Balaban's convention directly.
- Convex combination 3.2: for each monomial, Σ_τ w_τ(s)Π_{Δ∈S}τ(Δ) = Π_{Δ∈S}s(Δ)·Π_{Δ∉S}(s(Δ) + 1 − s(Δ)) = Π_{Δ∈S}s(Δ). ✓. Finite sum over τ (finite torus) and absolute convergence (W) allow the swap. Corner C_τ = walk sum with walks meeting {τ = 0} deleted. ✓. One variable per cube (p. 3, (2.8)), so the multilinear structure is the true one. CONFIRMED. After the 4.3 correction it is no longer load-bearing (symmetry is not needed).
