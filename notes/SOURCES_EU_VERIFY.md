## 4. Item 3: transport-and-back, dressed extension, constraint error
Numerical counterexample (/tmp/eu_verify/dressed.py; d = 2, N = 3, L_u = 4, SU(2) adjoint, axial paths from c_−, Q main term only). Random non-flat background U_b = exp(iεX_b): diagonal blocks of Q_U𝓔_U are I to 2e−14 (same path both ways), off-diagonal blocks are not zero. ‖Q_U𝓔_U − I‖ = 2.14e−2, 4.35e−2, 8.85e−2, 1.77e−1 at ε = 0.02, 0.04, 0.08, 0.16 (ratio/ε = 1.07–1.11, linear). Pure gauge U = g(x)g(x+e)^{−1}: ‖Q_U𝓔_U − I‖ = 8e−14. So "exact by transport and back" is FALSE for c ≠ c′, as claimed; the error is linear in the curvature.
Sign-cancellation argument: correct. Free identity Σ_y w_{c′}(y)E_0(y, c) = 0 for c′ ≠ c holds with E_0 ≠ 0 on the corridor of c′, so it is a cancellation; y-dependent rotations break it.
One-slice claim: checked geometry. Corridor of c covers μ-positions [0, 2N−2] (triangular weights), c ± e_μ cover [N, 3N−2] and [−N, N−2]; only position N−1 is private; weight on it 1/N; field ~N there, gradient ~N², energy ~N³. CONFIRMED.
Crux ‖Q(U)𝓔_U − I‖ ≤ cα_F. Pure-gauge invariance makes the error depend only on loop holonomies; lattice Stokes gives α_F·Area; Schur gives ε_Q ≤ α_F·c_St·ν_2 + ε_Q″. The α_F part is explicit up to untracked lattice-sum factors (c_St ≤ 4d, ν_2 ≈ 57 at d = 4, N = 5, so c ≈ 900, crude). ε_Q″ ≤ 2C′_1α_0·(Σ|E_0|-type constant) by CMP 98 (143) [V §3]; C′_1(d, L) is not printed. So uniform invertibility holds for α_F, α_0 small, but c is not fully explicit. Uniformity in k needs ν_2 bounded uniformly in N; that is [N] only (N = 3, 5; L_u not converged). E_0 is bounded and Lipschitz uniformly in N by a potential-theory argument (Q*δ is a bounded density on a unit region), so uniform moments are plausible; exponential decay uniform in k is not proved in SOURCES_EU.
Grade item 3: CONFIRMED (falsity, dressed construction, linear constraint error), with the caveat that the constant is explicit only for the α_F part and uniform-in-k moments are numerical.

## 5. Item 4: IMS patching and the 2/3 power
Cost model in §4.5: holonomy error α_F·d·(RΓ_1 + Γ_2) (loop = thin quadrilateral o → c → y → c′ → o, area ≤ R·(|y − c| + |y − c′|), because the kernel has O(1) range), patching error n_dΓ_2/R² (IMS double commutator, |∇φ| ≤ 1/R). Minimize aR + b/R² with a = α_F dΓ_1, b = n_dΓ_2: R* = (2b/a)^{1/3} ∝ α_F^{−1/3}, minimum = 3·2^{−2/3}a^{2/3}b^{1/3} ∝ α_F^{2/3}. So 2/3 is correct for this model and the formula for C_G matches.
The brief's alternative (holonomy ∝ α_Fℓ², whole-patch area) gives ℓ ∝ α_F^{−1/4} and total ∝ α_F^{1/2}. That is WORSE than 2/3 for small α_F; the author's thin-loop area R·O(1) is the right one because the kernel decays on the unit scale. The 2/3 is an artifact of patching in the sense that it comes from IMS + a frame error linear in R; a frame-free argument (magnetic-calculus type) could give power 1, as the author says. Not proved.
IMS identity: G = Σφ_iGφ_i + ½Σ[φ_i, [φ_i, G]] for Σφ_i² = 1 holds for any bounded G; the double-commutator kernel (φ_i(c) − φ_i(c′))²G^U(c, c′) is bounded by Schur with |G| — legitimate for an error term. Main term: in the patch frame φ_iG^Uφ_i = φ_i(G ⊗ I)φ_i + holonomy error, and ‖G‖ = K_0 (Gram matrix of ∇E_0). Correct.
Arithmetic re-done: γ_1 = 67.9, γ_2 = 178.1, ν_2 = 57.2, Γ_1 = 3.8e3, Γ_2 = 2.0e4, C_G = 7.9e4, c_{2/3} = 3.0e3 (K_0 = 195) or 4.0e3 (K_0 = 146.7, N = 5); Mα_0 ≲ 1.9e−7 for K ≤ 1.1K_0. All match.
Does K → K_0 as Mα_0 → 0 follow? The algebra is right: every error term carries α_F^{2/3}, α_F, or α_0. It is a proof only conditional on (a) Γ_j, ν_j bounded uniformly in k (numerical at N = 3, 5 only; decay not proved), (b) lattice-sum vs η^d-sum factors, (c) the boundary cutoff and (d) the gauge-fixing term, both [I]. So: INDICATED, not proved. Linear form: not proved (author agrees).
Grade item 4: CONFIRMED as a sketch with the author's own [I] labels; the status "sufficient for CDC" must read "sufficient once (a)–(d) are closed".
