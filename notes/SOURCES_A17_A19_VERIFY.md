## V6. Fallback ω and MA2 §4.4 Cauchy radius
- Geometry the author used: not "disc of radius ½ inside disc of radius 2". It is a one-variable slice ζ ↦ F(X + ζŶ), analytic on |ζ| < (1−ρ)R, real on the real diameter; two-constants on the upper half-disc; target point ζ = i‖Y‖_∞ with s = ‖Y‖_∞/((1−ρ)R) ≤ ρ/(1−ρ). Map w = ((1+z)/(1−z))²: diameter → (0,∞), semicircle → (−∞,0) (checked numerically: t = 0.3 → 3.45, t = −0.7 → 0.031, e^{i} → −3.35). ω(is) = arg(w)/π = (4/π)arctan s. ρ = ¼ ⇒ s ≤ ⅓ ⇒ ω = 0.40967 (python -I, two methods agree). Ball_{R/4} = {|B| < ½C_1ε_1} since R = 2C_1ε_1. CONFIRMED.
