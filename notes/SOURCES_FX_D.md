## 3. Direction of "fine" and the size of the radii [V + P]
- Convention [V, THEOREM2_PROOF_v4 §1.1]: "ε = L^{−K}, so log(L^kε)^{−1} = (K − k) log L. u_k := 1/g_k²." Scale k = 0 is the bare lattice (spacing ε). Scale k = K is the unit lattice, with g_K = g fixed. §1.3 (c′): "for all 0 ≤ m ≤ n ≤ K: u_n + β(n − m) − D′ ≤ u_m ≤ u_n + B′(n − m)."
- Consequence [P]. Take n = K: g_m^{−2} ≥ g^{−2} + β(K − m) − D′. At fixed physical scale and ε → 0 (K → ∞), the fine scales are m = O(1), and g_m² ≤ (g^{−2} + β(K − m) − D′)^{−1} → 0. So at fine scales g_m is SMALLEST, not largest. The brief's reading "fine-scale R-terms live where g_j is largest (≈ g_0 small but fixed)" is wrong: g_0 = g_0(ε, g) → 0 as ε → 0 (asymptotic freedom, Balaban Thm 2 (0.31) [V in v4 §1.1]). The "IR" direction j → K has g_j → g, the largest value. D4D5 l. 86 [V] states the same: "their radius τ(X) ∝ R̄_m^{−4} → 0 as ε → 0, because g_m → 0 at the finest scales."
- Three different radii appear in the files. They must not be mixed.
  (a) Field-space radii α_{i,j} = g_jC_i(log g_j^{−2})^{q_i} [V, IEPS_LF §3–§4]. They bound the background fields (U, J, A) of the analyticity domain U^c_j. They shrink like g_j·polylog at fine scales. They are NOT radii in the source variable.
  (b) Coupling radius ρ_0 (relative disc |g − x| < ρ_0x) [V, HHOL_LF §1, §4.4]. Fixed (ρ_0 = 0.1), uniform in k. HHOL_LF §5.4 [V] shows a scale-dependent ρ_j ∝ x_j² "would have been fatal" for N3.
  (c) Source radius τ_m(Γ) in ζ (sup norm of the source perturbation, units of r). This is the radius of (FX2) and of (FX-D). D3 model: τ = c_τr/(E_0R̄_m⁴), R̄_m = 100MR_m, R_m ≤ C_R(log g_m^{−2})^{p_R}. With (c′): R̄_m⁴ ≤ (100MC_R)⁴(log(g^{−2} + β′(K − m)))^{4p_R}. So the D3 radius shrinks like (log(K − m))^{−4p_R} at fine scales: polylog in log(1/λ_m), not like g_m and not like L^{−m}. HHOL_LF §2 [V]: "R_k → ∞ like (log k)^r … sup_k R_k = ∞ in the infinite-K limit."
- Answer to the brief's question (2) [P]. In the D3 model the source radius of the fine-scale R-terms does go to 0 as ε → 0, at a polylog rate. The worry in IV12_VERIFY is real for that model. It is about the fine (UV) end m → 0, not the IR end.

## 4. The compensating mechanism: shrinking field radius gives a non-shrinking source radius [P, given FX_O23 §3–§4]
Lemma FX-D. Let γ ≤ γ_Φ(M) (defined below), c ≤ ½, r ≤ 1. For every scale m ∈ {0, …, K} and every renormalizable component X_i at scale m, the (1.100) R-ratio of CMP 122 I, with sourced weight (choice B) or with the f-independent weight plus the moved term (choice A), is holomorphic in ζ on {‖ζ‖_∞ ≤ c·r} and non-vanishing there, with |D_i(f + ζ)| ≥ ½D_i(f) for real f ∈ F_{r/2}. The radius c·r is independent of m, K, ε, and |Λ_i|.
Proof.
 Step 1 (what the source touches) [V, FX_O23 §3, VERIFY §1]. The denominator is ∫dV′_{Λ_i}δ_{G_i}(V′)χ(Λ_i)exp[−w_mA(ζ_i, U_{m,X_i}(V′V_{Λ_i}))], with the bare Wilson action only (no E-, R-, B-terms). The source enters only through the weight w_m = g_m^{−2} + d_B + d_S (D3W8 §1.1). So σ_W := −Σ_{p⊂Λ_i}δw_m(p)ζ_i(p)P_p is the whole perturbation.
 Step 2 (the field radius enters here). On supp χ(Λ_i) and under χ_m, every scale-m plaquette that depends on V′ obeys |U_p − 1| ≤ O(1)ε_m, ε_m = g_mp_0(g_m) [V, FX_O23_VERIFY §2–§3 = N2]. So P_p ≤ O(1)g_m²p_0(g_m)². This is the field-space smallness (a) of §3: it shrinks with g_m.
 Step 3 (count). The number of scale-m plaquettes in Λ_i is ≤ O(1)(100MR_m)⁴ [V, CMP 122 I §1 (i) via FX_O23 §4(b)]. It grows at fine scales, but only polylog.
 Step 4 (product). With |δw_m| ≤ (3/2)‖ζ‖_∞ (N3 = B18):
   |σ_W| ≤ (3/2)‖ζ‖_∞·O(1)g_m²p_0(g_m)²(100MR_m)⁴ = ‖ζ‖_∞·Φ(g_m),
   Φ(g) := C(M)g²A_0²C_R⁴(log g^{−2})^{q}, q := 2p_0 + 4p_R.
 Step 5 (monotonicity, uniform sup) [P]. Put y = log g^{−2}. Then Φ = C′e^{−y}y^q, and d/dy(e^{−y}y^q) = e^{−y}y^{q−1}(q − y) < 0 for y > q. So for γ ≤ e^{−q/2}, Φ is increasing on ]0, γ] and sup_{g≤γ}Φ(g) = Φ(γ). Define γ_Φ(M) by Φ(γ_Φ) = 1 (and γ_Φ ≤ e^{−q/2}). For γ ≤ γ_Φ and every m: |σ_W| ≤ ‖ζ‖_∞ ≤ c·r ≤ ½. Only g_m ≤ γ is used, and (c′) gives g_m ≤ γ at every m ≤ K (Theorem 2w (b)). As g_m → 0 at the fine end, Φ(g_m) → 0: the fine scales are the EASIEST, not the hardest.
 Step 6 (non-vanishing). Positivity of the real integrand (N1) and Lemma D3.1 (|σ| ≤ ½ ⇒ |∫e^{σ}dμ| ≥ ½∫dμ) give |D_i(f + ζ)| ≥ ½D_i(f). Holomorphy: finite-dimensional compact integral, entire integrand in ζ. Choice A: the ratio is ζ-free; the moved term exp(−Σ(d_B + d_S)ζ_iP_p) has the same Φ-bound and is a small local term of the (1.68)–(1.69) type [V FX_O23 §4(e); bookkeeping "plausible, not checked", VERIFY item 1]. ∎
Compare with the brief's proposed mechanism. The brief suggested "radius ∝ g_j, size ∝ g_j, Cauchy gives O(1)". The actual mechanism is one step stronger. The source couples to P_p, and P_p = O(ε_m²) = O(g_m²·polylog) on the small-field support of the denominator. So the source's effect on the denominator is O(‖ζ‖·g_m²·polylog·R̄_m⁴) = o(‖ζ‖). The radius in ζ does not shrink at all; there is nothing to compensate in a Cauchy estimate. The D3 loss R̄_m^{−4} came from a modelling error (E-, R-, B-terms placed in the denominator, σ_E = O(E_0τ|Y|/r)), which FX_O23 §3 removed by reading CMP 122 I p. 201 on the page image.
The large-field numerators (T′ operations, fine histories) are O3: modulus domination |e^{−(w+δw)ΣζP_p}| ≤ e^{−(1−θ_W)wΣζP_p}, θ_W ≤ 6.5γ²r, radius c = 1 [V, FX_O23 §5 conclusion; VERIFY item 2: conditional on N3]. Again only g_m ≤ γ is used, so it is uniform at the fine end.

## 5. What (L1) needs from (FX-D), and the fixed-polydisc statement [P given inputs]

5.2 Radius of a unit-scale activity [P given A–C]. After Step A, R_fin(X; ·) is a finite sum (finite lattice) of products of: E-terms (radius r, S1(c)); R-ratios of every past scale m (radius c·r, Lemma FX-D, §4); large-field T′ numerators with their fine histories (radius r, O3); Mayer links e^{V} − 1 of these; and Step A's final T′_K. Each factor is holomorphic on P_* := {‖ζ‖_∞ ≤ c_*r, ‖∇ζ‖_∞ ≤ ρ_1/2}, c_* := min(c, ½). O3's modulus domination gives every UPPER bound of (1.73), (1.79), (1.89), (1.92), (1.97), (1.100) on all of P_* with γ_0 → γ_0′ ≥ γ_0/4 [V, FX_O23 §5]. The Cammarota/Kotecký–Preiss convergence then holds on P_* with the same constants, so R_fin(X; ·) is holomorphic on P_* (Weierstrass, uniform convergence) and |R_fin(X; ζ)| ≤ e^{−p_0(γ)}e^{−κ′d_K(X)} =: M_X on P_* [R to FX §6.1 bound, O1 verified]. No factor in this list has a radius that depends on m. The only division that could break this, (1.103) by T′_k(Y_i)1 (O4), is absent in Balaban's main form (C13) [V, FX_O23_VERIFY item 5].
5.3 The (L1) sup bound from 5.2 [P]. Let t_i := z_iN(f_i)/(c_*r). On the (L1) polydisc with constant c ≤ c_*, |t_i| ≤ 1 and f(t) ∈ P_* (disjoint supports: each lattice difference involves one f_i; B21_E14C Step 0 [V]). Fix X; let I(X) = {i : supp f_i ∩ X ≠ ∅}. F_X(t) := R_fin(X; f(t)) depends only on t_i, i ∈ I(X) (FX1), is holomorphic on the closed unit polydisc, and |F_X| ≤ M_X. Telescope over i ∈ I(X) in a fixed order; each step changes one variable: by the Schwarz lemma for g(s) = F_X(…, s, 0, …) − F_X(…, 0, 0, …), |g(s)| ≤ 2M_X|s|. So |F_X(t) − F_X(0)| ≤ 2M_XΣ_{i∈I(X)}|t_i|. Sum over X:
   Σ_X|R^f_fin(X) − R^0_fin(X)| ≤ 2Σ_i|t_i|Σ_{X∩supp f_i≠∅}M_X ≤ 2e^{−p_0(γ)}C_κΣ_i|t_i|(1 + |supp f_i|_1),
 with C_κ := sup_□ Σ_{X∋□}e^{−κ′d_K(X)} ≤ Σ_s e^{c_0s}e^{−κ′(s−1)} < ∞ (FX4, Step D count [V FX §6.4]) and |supp f_i|_1 = number of unit cubes meeting supp f_i. This is the R_fin part of (L1) with C_0 ≥ 2e^{−p_0(γ)}C_κ/c_*. It is free of ε, K, ℓ, V [P].
