3.2 The form used [V, from 3.1].
 G_{k+1} := the Euclidean maps of the continuum torus T that map the block lattice T^{(k+1)} onto itself. It contains the translations by block-lattice vectors (multiples of L^{k+1}η) and the hypercubic point group (90° rotations and reflections) about block-lattice points. It does NOT contain the unit-lattice translations that are not block-lattice translations. For R^{(j)} the group is smaller still: the maps that keep the MR_j-cube partition invariant. The covariance acts on the fluctuation field by an orthogonal map O_r (bond permutation, with the orientation twist of (2.18)), and on U by (rU)(b) = U(rb). The property of the covariance that is used is
 (E) O_r C^{(k)}(U) O_r^{−1} = C^{(k)}(rU) for r ∈ G_{k+1} (whole space), equivalently O_r(C*Δ^{(k)}C)(U)O_r^{−1} = (C*Δ^{(k)}C)(rU),
 together with invariance of the χ-functions. Euclidean covariance is used only for the whole-space objects (Ω_j = T_η), never for the Ω-sequence operators. So the full unit-lattice symmetry group is never needed; only G_{k+1} (and the partition-preserving subgroup for R^{(j)}).

3.3 Does the project's C_f satisfy (E) jointly with d_S? [P, short]
 Write the source as a plaquette function d_S. Define (r·d_S)(p) := d_S(r^{−1}p). Claim: for r ∈ G_{k+1}, O_r C_f(U; d_S)O_r^{−1} = C_f(rU; r·d_S).
 Proof. C_f = (A_exp − g²𝒲_S)^{−1}, 𝒲_S = C*𝒱_SC, 𝒱_S = H_1*D_SH_1 + 𝒱_S^{(2)}.
