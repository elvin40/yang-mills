# Yang–Mills on a torus along Balaban's renormalization group

Working notes, lemmas, verifier reports, and numerics toward (1) Balaban's unpublished Theorem 2 (running-coupling control, CMP 109 (1987) p. 259) and (2) a finite-torus existence theorem for 4D SU(2) lattice Yang–Mills in compactness form.

Status: every statement carries a tag (proved / verified / reduced / open). Nothing here is a complete proof of either target. PLAN.md holds the dated status lines; THEOREM2_PROOF.md and ASSEMBLY.md are the assembly documents; files named *_VERIFY.md are independent verification passes.

Independence note: these notes were written on 2026-10-27 and 2026-10-28 (see commit dates, which equal the files' modification times). On the night of 2026-10-27 a web sweep (reports/ONLINE_SWEEP.md) found the public account by Ethan Sussman and Levent Alpöge, github.com/ethanwsussman/Yang--Mills-LLM-experiment, which follows the same route and reaches the same open one-loop comparison lemma. That account was not read by any derivation here; reports/SUSSMAN_ALPOGE_MAP.md compares the two.

The Balaban papers (Communications in Mathematical Physics, 1984–1989) are not included.
